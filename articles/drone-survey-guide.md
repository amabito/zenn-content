# 結論から言う

**ドローン測量は「15分で1ha」。ただし、失敗すると全部やり直し。**

「ドローン測量を始めたいけど、何から手をつければいい？」

導入5年で経験した失敗と、そこから学んだ実践ノウハウを共有する。

**この記事で得られること:**
- 失敗しない機材選び
- 資格・許可の取り方
- 撮影から納品までの全フロー

# ドローン測量とは

## 従来測量との比較

| 項目 | 従来（TS） | ドローン |
|------|----------|---------|
| 時間 | 1日/1ha | **15分/1ha** |
| 人員 | 2〜3人 | **1人** |
| 精度 | ◎（mm級） | ○（cm級） |
| 危険箇所 | 人が入る | **立入不要** |
| 初期投資 | 中 | 高 |

**時間効率は圧倒的。ただし精度はトータルステーションに劣る。**

# 機材選び

## ドローン本体

### 測量向けおすすめ

| 機種 | 価格 | 特徴 | おすすめ度 |
|------|------|------|----------|
| DJI Mavic 3 Enterprise | 70万円 | RTK対応、コンパクト | ◎ |
| DJI Matrice 350 RTK | 150万円 | 業務用、高耐久 | ◎ |
| DJI Phantom 4 RTK | 販売終了 | 名機、中古あり | ○ |
| Autel EVO II Pro RTK | 80万円 | DJI対抗 | ○ |

**初めてならMavic 3 Enterpriseが最適解。**

### RTKの重要性

```
RTKなし: 後処理でGCP必要 → 精度cm級
RTKあり: リアルタイム補正 → 精度2-3cm
```

**本気で測量するならRTK一択。**

## カメラ

### 内蔵カメラで十分なケース

- 写真測量（SfM）
- オルソ画像作成
- 一般的な地形測量

### 別途必要なケース

- LiDAR測量 → 専用ペイロード
- 赤外線調査 → サーマルカメラ
- 高解像度撮影 → フルサイズミラーレス

## 周辺機器

| 機器 | 必要度 | 価格 |
|------|--------|------|
| 予備バッテリー（3本） | ◎ | 10万円 |
| RTK基地局 or NTRIP | ◎ | 50〜100万円 |
| GCP（対空標識） | ○ | 5万円 |
| モニター（タブレット） | ○ | 5万円 |
| 風速計 | ○ | 1万円 |
| ケース | ◎ | 3万円 |

# 撮影テクニック

## 基本設定

| 項目 | 推奨値 |
|------|--------|
| オーバーラップ（進行方向） | 80%以上 |
| サイドラップ（横方向） | 60%以上 |
| 高度 | 対象物の1.5〜2倍 |
| 速度 | 5〜10m/s |
| シャッター速度 | 1/500以上 |
| ISO | 100〜400 |

## よくある失敗

### 失敗1: オーバーラップ不足

```
症状: 点群に穴ができる
原因: 重複率60%以下
対策: 80%以上に設定
```

### 失敗2: 影の影響

```
症状: 色ムラ、マッチング失敗
原因: 強い日差し
対策: 曇りの日を選ぶ、早朝撮影
```

### 失敗3: 動く物体

```
症状: ノイズ、歪み
原因: 車両、人、植生の揺れ
対策: 交通規制、早朝撮影
```

### 失敗4: 単調なテクスチャ

```
症状: マッチング失敗
原因: コンクリート、砂地
対策: 近接撮影を追加
```

# データ処理

## ソフトウェア

| ソフト | 価格 | 特徴 |
|--------|------|------|
| Metashape | 20〜60万円 | 定番、高精度 |
| Pix4D | 50万円/年 | クラウド対応 |
| DJI Terra | 20万円/年 | DJI機に最適化 |
| KUMIKI | 従量課金 | 国産、NETIS登録 |
| WebODM | 無料 | オープンソース |

**予算があればMetashape、なければWebODMから。**

## 処理フロー

```
1. 画像取り込み
    ↓
2. アライメント（カメラ位置推定）
    ↓
3. GCP配置（RTKなしの場合）
    ↓
4. 密な点群生成
    ↓
5. メッシュ生成
    ↓
6. オルソ画像生成
    ↓
7. DSM/DTM生成
    ↓
8. 出力（LAS, TIF, DXF等）
```

## 精度検証

| 検証項目 | 許容値（一般） |
|---------|--------------|
| 水平精度 | ±5cm |
| 鉛直精度 | ±10cm |
| GCP残差 | ±3cm |
| チェックポイント残差 | ±5cm |

```
投資回収期間 = 初期投資 ÷ (案件単価 × 年間案件数 - ランニングコスト)
```

**年間15件こなせば1年で回収可能。**

# 3DGS活用

## 点群 vs 3DGS

| 項目 | 点群 | 3DGS |
|------|------|------|
| 見た目 | 粒状感 | **写真品質** |
| サイズ | 大 | 中 |
| 精度 | ◎ | ○ |
| 発注者ウケ | △ | **◎** |

**測量は点群、プレゼンは3DGS。使い分けが重要。**

## 3DGS処理フロー

```
ドローン撮影
    ↓
COLMAP（カメラポーズ推定）
    ↓
3DGS学習（HyperRasterizer等）
    ↓
PLY出力
    ↓
ビューア表示
```

詳細は別記事で解説。
