# 結論から言う

**物流倉庫を3D Gaussian Splattingで3Dモデル化すると、棚卸し時間が1/3、レイアウト検討が1/5になる。**

スマホやドローンで撮影するだけで、倉庫全体のフォトリアルな3Dモデルが15分で完成する。物流業界の人手不足を「現場のデジタルツイン化」で解決するアプローチだ。

---

# 物流業界が直面する3つの壁

| 課題 | 数字 |
|------|------|
| 市場規模 | 約25兆円（国内物流） |
| EC取扱高 | 約21兆円（年10%成長） |
| 2024年問題 | ドライバー14万人不足（2030年予測） |
| 倉庫人材 | 有効求人倍率2.0倍超 |

ECの急増で倉庫の処理量は増える一方、人は足りない。**「少ない人数で、より広い倉庫を、より速く回す」** ことが生存条件になっている。

---

# 3DGSとは（30秒で理解）

```
撮影（スマホ/ドローン）
  ↓
画像群（50〜200枚）
  ↓
3D Gaussian Splatting
  ├── カメラ位置推定（SfM）
  ├── 3Dガウシアン生成
  └── 最適化（5〜30分）
  ↓
フォトリアル3Dモデル
  ├── ブラウザで閲覧可能
  ├── 任意視点から確認
  └── 寸法計測も可能
```

従来の3Dスキャン（LiDAR等）と比べ、**専用機材不要・処理時間1/10・コスト1/5**が最大の特徴。

# 物流での活用シーン

## 1. 倉庫レイアウト最適化

| 項目 | Before | After（3DGS導入後） |
|------|--------|---------------------|
| 現地調査 | 2〜3日 | スマホ撮影30分 |
| レイアウト検討 | 図面ベース、2週間 | 3Dモデル上で2〜3日 |
| 関係者共有 | 現地立会い必須 | ブラウザで共有 |
| 手戻り | 施工後に発覚 | 事前にシミュレーション |

**レイアウト変更の検討期間が1/5に短縮。** 棚の配置、通路幅、ピッキング動線を3Dモデル上で検討できる。

## 2. 棚卸し・在庫管理の3D化

定期的に倉庫を撮影し、3Dモデルを比較する。

- 棚の空き状況を俯瞰で把握
- 時系列での在庫量変化を可視化
- 遠隔拠点の状況をリアルタイム確認

**棚卸し作業時間を従来の1/3に削減した事例あり。**

## 3. 配送センター新設・改修の事前検討

既存施設を3Dモデル化し、改修案を複数パターン比較できる。設計会社との打ち合わせも3Dモデルを共有するだけで完結する。

## 4. 安全教育・作業手順の3D化

新人教育で「実際の倉庫の3Dモデル」を使い、フォークリフトの動線や危険箇所を事前に学習。現場に出る前にリスクを理解できる。

## 5. ロボット/AGVの経路最適化

3Dモデルから**障害物マップを自動生成**し、AGV（無人搬送車）やピッキングロボットの経路計画に活用。導入前のシミュレーションコストを大幅に削減。

# 導入ステップ

```
Step 1: 撮影（1日）
  └── スマホ or ドローンで倉庫内を撮影
  └── 200〜500枚、動画からの切り出しでもOK

Step 2: 3Dモデル生成（半日）
  └── 3DGSで処理（GPU搭載PCで15〜30分）
  └── 商用利用可能なツールを選定

Step 3: 活用・運用（継続）
  └── WebGPUビューアでブラウザ共有
  └── 月1回の定期撮影でモデル更新
```

# コスト比較

| 項目 | LiDARスキャン | 3DGS |
|------|-------------|------|
| 機材費 | 300〜1,000万円 | スマホ（0円） |
| 計測時間 | 1〜2日/拠点 | 30分〜1時間/拠点 |
| 専門技術者 | 必要 | 不要 |
| データ処理 | 外注（50〜100万円） | 自社PC（GPU必要） |
| 年間運用コスト | 500万円〜 | 50万円〜 |
| 精度 | mm単位 | cm単位 |

**精度がmm単位で必要な場面以外は、3DGSが圧倒的にコスパが良い。**

# 課題と対策

| 課題 | 詳細 | 対策 |
|------|------|------|
| 照明環境 | 倉庫内は暗い箇所が多い | LED投光器併用、HDR撮影 |
| 動的物体 | フォークリフト・作業員が写り込む | 深夜/早朝の静止状態で撮影 |
| 商用ライセンス | オリジナル3DGSは商用不可 | Apache 2.0ツールを使用 |

商用ライセンスについては、**[HyperRasterizer](https://github.com/amabito/hyper-rasterizer)（Apache 2.0）** がDGR比1.45倍の速度で商用利用可能。自社サービスへの組み込みにも制約がない。
