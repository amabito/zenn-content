# 結論から言う

**中小建設会社が生き残るには「選択と集中」しかない。**

建設コンサルタントとして15年、数百の建設会社と仕事をしてきた。生き残る会社と消える会社の違いを見てきた。この記事では、中小建設会社が取るべき5つの戦略を解説する。

---

# 業界の現状

## 数字で見る危機

| 指標 | 数値 |
|------|------|
| 建設業許可業者数 | 約47万社 |
| うち中小企業 | **99%** |
| 55歳以上の割合 | 35% |
| 29歳以下の割合 | 12% |
| 10年後の技能者不足 | 94万人 |

**10年後、現場を支える人がいなくなる。**

## 淘汰の加速

```
2020年: 約50万社
2025年: 約47万社（-6%）
2030年: 約40万社（予測）
2035年: 約30万社（予測）
```

**10年で3割の会社が消える可能性。**

---

# 戦略1: ニッチ分野で地域No.1になる

## 考え方

```
NG: 「なんでもやります」
OK: 「○○なら当社」
```

**「何でも屋」は価格競争に巻き込まれる。**

## 具体例

| ニッチ分野 | 強みの作り方 |
|-----------|-------------|
| 橋梁補修 | 資格取得、専門機材導入 |
| のり面工事 | 特殊技術の蓄積 |
| 災害復旧 | 24時間対応体制 |
| 解体工事 | 環境対応技術 |
| 維持管理 | 長期契約の獲得 |

## 成功事例

**A社（従業員30名、地方）**

```
Before: 土木一般、価格競争で疲弊
After: 「橋梁点検・補修」に特化

結果:
- 売上: 8億円 → 12億円（+50%）
- 利益率: 2% → 8%（+6pt）
- 競合: 県内で3社のみ
```

# 戦略2: ICT/DXで差別化する

## なぜ今か

```
2024年: 働き方改革（残業規制）
2025年: i-Construction加速
2026年: 大手と中小の差が決定的に
```

**今やらなければ、二度と追いつけない。**

## 導入ステップ

| フェーズ | 内容 | 投資額 |
|---------|------|--------|
| 1 | 写真管理アプリ | 月5万円 |
| 2 | ドローン測量 | 200万円 |
| 3 | ICT建機（リース） | 月30万円 |
| 4 | BIM/CIM対応 | 500万円 |

**小さく始めて、成功体験を積む。**

## 補助金活用

| 補助金 | 上限 | 対象 |
|--------|------|------|
| IT導入補助金 | 450万円 | ソフト |
| ものづくり補助金 | 3,000万円 | 機材 |
| 省力化投資補助金 | - | ICT建機 |

**使えるものは全部使う。**

# 戦略3: 人材で勝負する

## 採用の現実

```
大手: 新卒採用できる
中小: 「誰も来ない」
```

**正攻法では勝てない。**

## 中小の採用戦略

### 戦略A: 地元密着

```
「転勤なし」「地元で働ける」をアピール
→ 都会から戻りたいUターン層を狙う
```

### 戦略B: 未経験者採用

```
異業種からの転職者を積極採用
→ 教育に投資し、一から育てる
```

### 戦略C: 外国人技能実習

```
技能実習生・特定技能を活用
→ 長期戦力化の仕組みを作る
```

### 戦略D: シニア活用

```
定年退職した技術者を再雇用
→ 週3日勤務など柔軟に
```

## 定着の仕組み

| 施策 | 効果 |
|------|------|
| 資格取得支援 | 成長実感 |
| 給与の見える化 | 納得感 |
| 残業削減 | ワークライフバランス |
| 社長との距離感 | 中小の強み |

---

# 戦略4: 元請け化を進める

## 下請けの限界

```
元請け利益率: 10%
下請け利益率: 3〜5%
孫請け利益率: 1〜2%
```

**下請けでは永遠に儲からない。**

## 元請けになる方法

### 方法A: 経審点を上げる

```
経営事項審査（経審）の点数を上げる
→ 入札参加資格を得る
→ 公共工事の元請けに
```

| 項目 | 対策 |
|------|------|
| 完成工事高 | 売上を伸ばす |
| 技術力 | 技術者を増やす |
| 社会性 | 安全対策、福利厚生 |
| 経営状況 | 財務体質改善 |

### 方法B: 民間工事を開拓

```
公共: 入札資格が必要
民間: 実績と信頼で受注可能
```

**民間は営業力次第。**

### 方法C: 維持管理で食い込む

```
新設工事: 大手が強い
維持管理: 地元が有利
```

**「守りの仕事」を取りに行く。**

# 戦略5: 事業承継・M&Aを検討する

## 後継者問題の深刻さ

```
建設業の後継者不在率: 60%以上
→ 3社に2社は後継者がいない
```

## 選択肢

| 選択肢 | 内容 |
|--------|------|
| 親族承継 | 子供に継がせる |
| 社員承継 | 番頭格に譲る |
| M&A（売却） | 他社に売る |
| 廃業 | 畳む |

## M&Aのメリット

**売り手（中小）**
- 従業員の雇用継続
- 創業者利益の確保
- 借入金の整理

**買い手（大手・中堅）**
- 地域拠点の獲得
- 技術者の確保
- 実績・許可の取得

## 企業価値の目安

```
企業価値 ≒ 純資産 + 営業利益 × 3〜5年分
```

**黒字なら売れる。早めに準備を。**

---

# やってはいけないこと

## NG1: 価格で勝負する

```
ダンピング → 利益なし → 品質低下 → 信用失墜 → 倒産
```

**安売りは死への片道切符。**

## NG2: 設備投資の先送り

```
「まだ大丈夫」→ 競合に差をつけられる → 手遅れ
```

**投資しないリスクの方が大きい。**

## NG3: 人材育成の放棄

```
「忙しくて教えられない」→ 若手が辞める → さらに忙しく → 崩壊
```

**教育は投資、コストではない。**

## NG4: 単独主義

```
「うちはうちでやる」→ 限界 → 淘汰
```

**協力会社、JV、連携を活用すべき。**
