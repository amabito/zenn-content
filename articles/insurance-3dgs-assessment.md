# 結論から言う

**3D Gaussian Splatting（3DGS）を使えば、損害査定の現場記録が「正確」「迅速」「改ざん困難」になる。**

査定員がスマホで現場を撮影するだけで、数分後には損害箇所の3Dモデルが完成する。写真では伝わらない奥行き・スケール・位置関係が、すべて3D空間上に記録される。

これは未来の話ではない。技術は既に実用段階にある。

---

# 保険業界が抱える3つの構造的課題

保険の損害査定は、いまだに「人が現場に行って写真を撮る」が基本だ。

**1. 査定員の慢性的不足**
自然災害の頻発で査定件数は増加傾向にある。一方で熟練査定員の高齢化・退職が進み、1件あたりの対応時間が延びている。

**2. 現場再訪問のコスト**
写真の撮り漏れ、角度不足、スケール不明。これらの理由で現場への再訪問が発生する。損保ジャパンの調査では、査定案件の約15-20%で追加確認が必要になるとされている。

**3. 不正請求の検出困難**
写真は2Dだ。損害の規模感を意図的に誇張したり、既存の損傷を事故に紛れ込ませることが可能になる。保険業界全体で不正請求による損失は年間数百億円規模と推計されている。

---

# 3DGSとは（30秒で理解）

3D Gaussian Splatting（3DGS）は、複数枚の写真から3Dモデルを生成する技術だ。

```
スマホで動画撮影（30秒〜2分）
    ↓
写真を数十〜数百枚に分解
    ↓
AIが3D空間を再構築
    ↓
ブラウザで閲覧可能な3Dモデル完成
```

従来の3Dスキャン（LiDAR等）と異なり、**専用機材が不要**。スマホ1台あれば、誰でもフォトリアルな3Dモデルを作成できる。

処理時間は対象の規模により5分〜30分程度。生成された3Dモデルはブラウザ上でリアルタイムに自由視点で閲覧できる。

# 保険での活用シーン

## 1. 自動車事故の3D記録

事故現場をスマホで撮影し、車両の損傷・道路状況・車両間の位置関係を3Dで保存する。

**従来の課題**: 写真20〜30枚では死角が生じ、衝突角度や変形量の正確な把握が困難。

**3DGSによる改善**: 車両を一周撮影するだけで全方位の損傷を3D記録。衝突シミュレーションの入力データとしても活用できる。

## 2. 火災・自然災害の損害3D記録

火災後の建物内部、台風による屋根損傷、浸水被害の痕跡。これらを3Dで記録すれば、遠隔地の専門査定員がデスクで詳細確認できる。

**ドローンとの組み合わせ**: 損保ジャパンやあいおいニッセイ同和損保では既にドローンによる災害調査を導入している。ドローン映像に3DGSを適用すれば、屋根上や危険箇所の3Dモデルを安全に生成可能だ。

## 3. 建物の事前状態記録（ベースライン）

火災保険や地震保険の契約時に、建物の3D状態を記録しておく。

損害発生後に同じ建物を再度3D化し、**Before/Afterの3D比較**を行うことで、損害範囲と程度を客観的に特定できる。

## 4. 不正請求の検出

3Dモデルには寸法情報が含まれる。申告された損害と3Dモデル上の実測値を比較すれば、**損害規模の誇張**を数値で検出できる。

また、過去の3Dベースラインとの差分解析により、**既存損傷の混入**も判別可能になる。

# 課題と対策

## プライバシー

3Dモデルには周囲の環境情報が含まれる。近隣住宅や通行人が映り込む可能性がある。

**対策**: 撮影範囲のガイドライン策定、自動マスキング処理の適用、データ保持期間の明確化。

## 精度の担保

3DGSの再構成精度は、撮影条件（照明、テクスチャ、遮蔽物）に依存する。

**対策**: 撮影プロトコルの標準化、品質スコアによる自動判定、基準未満の場合は再撮影を促すUX設計。

## 法的証拠能力

3Dモデルが裁判や調停で証拠として認められるか。現時点では判例が少ない。

**対策**: タイムスタンプ付きハッシュ値の記録、撮影メタデータの保全、電子署名の付与。ブロックチェーンとの組み合わせも検討の余地がある。
