# 結論から言う

**i-Construction 2.0の方向性は正しい。だが現場は追いついていない。**

「i-Con対応で何が変わったの？」「2.0って何が違うの？」

2016年のi-Construction開始から8年間、現場を見てきた建設コンサルタントが本音で語る。

**この記事で得られること:**
- i-Construction 1.0と2.0の違い
- 現場で実際に起きていること
- 本当に効果があった施策

---

# i-Constructionとは（おさらい）

## 1.0（2016年〜）

国土交通省が掲げた建設現場の生産性向上施策。

```
目標: 2025年までに生産性20%向上
手段: ICT土工、BIM/CIM、ドローン測量
```

## 2.0（2024年〜）

2024年4月に発表された次世代版。

```
目標: 2040年までに省人化30%、生産性1.5倍
手段: 自動施工、AI活用、データ連携
```

# 理想：こうなるはずだった

## ICT土工

```
従来: 測量→丁張り→施工→出来形測量
      ↓
ICT: ドローン測量→3Dデータ→MC建機→自動検査
```

**期待された効果:**
- 測量工数 50%削減
- 丁張り作業 ゼロ
- 手戻り 大幅減少

## BIM/CIM

```
従来: 2D図面 → 現場で立体化を想像 → 干渉発覚 → 手戻り
      ↓
BIM/CIM: 3Dモデルで事前に干渉チェック → 手戻りゼロ
```

**期待された効果:**
- 設計ミス 80%削減
- 協議時間 50%削減
- 維持管理コスト 30%削減

# 現実：8年経った今

## 数字で見る進捗

| 指標 | 目標 | 現実（2025年） |
|------|------|---------------|
| 生産性向上 | 20% | **10%程度** |
| BIM/CIM導入率 | 100%（原則適用） | **48%** |
| ICT活用工事率 | - | **直轄で8割、地方で3割** |

**目標の半分程度しか達成できていない。**

### 発注者（地方自治体）
> 「BIM/CIMで納品されても、見る環境がない」

# なぜギャップが生まれたか

## 原因1: 初期投資の壁

| 機材 | 価格 |
|------|------|
| ICT建機（MC/MG） | 3,000万円〜 |
| 3Dレーザースキャナー | 1,000〜3,000万円 |
| ドローン+ソフト | 200〜500万円 |
| BIMソフト | 年間100〜500万円 |

**建設業の99%は中小企業。** 資本金1,000万円以下が大半。

## 原因2: 人材不足

| 課題 | 現状 |
|------|------|
| ICT操作できる人 | 若手に偏在 |
| 教える人 | ベテランはアナログ世代 |
| 採用市場 | IT人材は建設業を選ばない |

**技術はあっても、使える人がいない。**

## 原因3: 発注者側の未整備

```
国交省: 「BIM/CIMで納品せよ」
現場: 「3Dモデル作りました」
地方自治体: 「...見れません」
```

**受け皿がないのに、投げ込んでいる状態。**

## 原因4: 二重作業問題

```
発注者: 「BIM/CIMで設計して」
でも: 「2D図面も出して」
結果: 3D作業 + 2D作業 = 作業量2倍
```

**効率化のはずが、非効率化している現場も。**

# うまくいっているケース

## ケース1: 大規模土工（高速道路）

```
条件:
- 発注者が国交省直轄
- 元請けが大手ゼネコン
- 工期が長い（3年以上）

結果:
- ICT建機フル活用
- 生産性30%向上
- 人員20%削減
```

**潤沢な予算と時間があれば機能する。**

## ケース2: 先進的な地方自治体

```
条件:
- 首長がDX推進派
- 専任のICT担当者を配置
- 段階的に導入

結果:
- 3年かけて全職員がBIM閲覧可能に
- 住民説明会で3D活用
- 議会でも好評
```

**トップダウンと時間があれば浸透する。**

## ケース3: 若手中心の中小企業

```
条件:
- 社長が40代以下
- 若手技術者が主力
- 「やってみよう」文化

結果:
- スマホ+タブレットから開始
- 無料ツールを活用
- 徐々にスケールアップ
```

**小さく始めて、成功体験を積む。**

# 現場からの提言

## 1. 「全部やる」をやめる

```
NG: 明日からBIM/CIM全面導入
OK: まず写真管理アプリから
```

## 2. 補助金を使い倒す

| 補助金 | 上限 | 対象 |
|--------|------|------|
| IT導入補助金 | 450万円 | ソフトウェア |
| ものづくり補助金 | 3,000万円 | 3D計測機器 |
| 省力化投資補助金 | - | ICT建機 |

**使える制度は全部使う。**

## 3. 発注者を巻き込む

```
NG: 「納品形式はBIM/CIMです」（一方通行）
OK: 「一緒にビューアの使い方を覚えませんか」
```

**発注者も困っている。一緒に解決する姿勢。**

## 4. 外部リソースを活用

```
- ICT施工は専門業者に外注
- BIMモデリングは外注
- 社員は「使う」ことに集中
```

**全部内製する必要はない。**

# i-Construction 2.0は成功するか

## 楽観シナリオ

```
2026年: 地方自治体もBIM閲覧環境整備
2028年: 中小企業にICT建機リースが普及
2030年: 自動施工が中規模現場にも展開
2040年: 省人化30%達成
```

## 悲観シナリオ

```
2026年: 依然として二重作業
2028年: 人材不足で導入進まず
2030年: 先進企業と後進企業の格差拡大
2040年: 省人化15%で頭打ち
```

## 現実的シナリオ

```
2026年: 直轄事業は概ね達成、地方は遅延
2028年: 中小企業の2割がICT対応
2030年: 業界再編（ICT非対応企業の淘汰）
2040年: 省人化20-25%で着地
```

# 生き残るために

## 大手の戦略

- 自前でICT部隊を持つ
- R&D投資を継続
- 中小企業をM&Aで取り込む

## 中小の戦略

- 特定分野に特化（ニッチトップ）
- 大手と組む（下請けとして生き残る）
- ICT対応で差別化

## 個人の戦略

- ICTスキルを身につける
- 資格（技術士、RCCM等）を取得
- 転職市場での価値を上げる
