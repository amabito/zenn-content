# 結論から言う

**建設業で最も儲けているのは「元請け」と「専門性の高いニッチ企業」。下請けは薄利。**

「建設業って儲かるの？」「どこにいけば稼げるの？」

業界15年の建設コンサルタントが、普段は語られない金の流れを暴露する。

**この記事で得られること:**
- 建設プロジェクトの金の流れ
- 利益率が高いポジション
- 下請けが稼げない構造的理由

---

# 建設プロジェクトの全体像

## 典型的な公共土木工事

```
国・自治体（発注者）
    │
    ├─ 設計業務 → 建設コンサルタント
    │
    ├─ 施工業務 → ゼネコン（元請け）
    │               ├─ 土工 → 土木会社（下請け）
    │               ├─ 舗装 → 舗装会社（下請け）
    │               ├─ 橋梁 → 橋梁会社（下請け）
    │               └─ ...
    │
    └─ 監理業務 → 建設コンサルタント
```

---

# 金額の内訳

## 10億円の道路工事の場合

| 項目 | 金額 | 割合 |
|------|------|------|
| 施工費（元請け契約） | 9億円 | 90% |
| 設計費 | 5,000万円 | 5% |
| 監理費 | 3,000万円 | 3% |
| その他 | 2,000万円 | 2% |

**施工費が圧倒的。設計は5%程度。**

---

# 施工の金の流れ

## 元請け（ゼネコン）の取り分

### 9億円の工事の場合

| 項目 | 金額 | 割合 |
|------|------|------|
| 契約金額 | 9億円 | 100% |
| 下請け発注 | 6.3億円 | 70% |
| 資材購入 | 0.9億円 | 10% |
| 自社経費 | 0.9億円 | 10% |
| **利益** | **0.9億円** | **10%** |

**元請けは「マネジメント料」として10%前後を取る。**

## 下請けの取り分

### 6.3億円の下請け工事

```
一次下請け（6.3億円）
    ├─ 自社施工: 2.5億円（40%）
    ├─ 二次下請けへ: 3.2億円（50%）
    └─ 利益: 0.6億円（10%）

二次下請け（3.2億円）
    ├─ 自社施工: 2.4億円（75%）
    ├─ 三次下請けへ: 0.5億円（15%）
    └─ 利益: 0.3億円（10%）

三次下請け（0.5億円）
    ├─ 自社施工: 0.45億円（90%）
    └─ 利益: 0.05億円（10%）
```

## 利益率の比較

| 階層 | 契約金額 | 利益 | 利益率 |
|------|---------|------|--------|
| 元請け | 9億円 | 9,000万円 | 10% |
| 一次下請け | 6.3億円 | 6,000万円 | 9.5% |
| 二次下請け | 3.2億円 | 3,000万円 | 9.4% |
| 三次下請け | 0.5億円 | 500万円 | 10% |

**利益「率」は同じでも、利益「額」は圧倒的に元請けが多い。**

# 設計の金の流れ

## 5,000万円の設計業務

| 項目 | 金額 | 割合 |
|------|------|------|
| 契約金額 | 5,000万円 | 100% |
| 人件費 | 3,250万円 | 65% |
| 外注費 | 750万円 | 15% |
| 経費 | 500万円 | 10% |
| **利益** | **500万円** | **10%** |

**人件費が過半数。人が命。**

## 元請け vs 下請け

| 項目 | 元請け | 下請け |
|------|--------|--------|
| 技術者ランク | 技師長〜主任技師 | 技師A〜C |
| 日額単価 | 5〜6万円 | 3〜4万円 |
| 利益率 | 10%前後 | 5%前後 |

**高単価の技術者を持つ会社が勝つ。**

# 誰が儲けているか

## ポジション別の収益性

| ポジション | 利益率 | 参入障壁 | 安定性 |
|-----------|--------|---------|--------|
| ゼネコン（大手） | 10〜15% | ◎ | ◎ |
| 専門工事会社（特殊技術） | 15〜20% | ◎ | ○ |
| 建設コンサル（大手） | 10〜12% | ◎ | ◎ |
| ゼネコン（中堅） | 5〜10% | ○ | ○ |
| 建設コンサル（中小） | 5〜8% | ○ | ○ |
| 一般土木（下請け） | 3〜5% | △ | △ |
| 労務（人工出し） | 1〜3% | × | × |

**「専門性」と「元請けポジション」が儲けの源泉。**

## 儲かる会社の共通点

| 特徴 | 内容 |
|------|------|
| 元請け比率が高い | 70%以上 |
| 専門性がある | 「○○なら」と言われる |
| 資格者が多い | 技術士、1級施工管理 |
| 固定費が低い | 身軽な経営 |
| 価格競争しない | 技術で勝負 |

# なぜ下請けは儲からないのか

## 構造的問題

### 問題1: 価格決定権がない

```
発注者 → 元請け: 価格交渉可能
元請け → 下請け: 「この金額でやれ」
```

### 問題2: 替えが効く

```
下請けA: 「値上げしてほしい」
元請け: 「じゃあBに頼む」
```

### 問題3: 情報格差

```
元請け: 発注者の予算を知っている
下請け: 知らない
```

## 脱却方法

| 方法 | 難易度 | 効果 |
|------|--------|------|
| 元請けになる | 高 | ◎ |
| 専門性で差別化 | 中 | ◎ |
| 複数元請けと取引 | 中 | ○ |
| 直接発注を狙う | 高 | ◎ |

# 業界再編の行方

## 今起きていること

```
大手: M&Aで中堅・中小を買収
中堅: 生き残りをかけて専門化
中小: 廃業 or 大手グループ入り
```

## 10年後の予想

| 階層 | 現在 | 10年後 |
|------|------|--------|
| 大手ゼネコン | 5社 | 3〜4社 |
| 中堅ゼネコン | 50社 | 30社 |
| 中小建設会社 | 47万社 | 30万社 |

**規模が二極化する。**

# 儲けるために何をすべきか

## ゼネコン・建設会社

| 戦略 | 内容 |
|------|------|

| ICT化 | 生産性向上で利益率改善 |

## 建設コンサルタント

| 戦略 | 内容 |
|------|------|

| 提案力強化 | プロポで勝つ |

|------|------|
| 資格取得 | 技術士、1級施工管理 |
| 専門性構築 | 「○○の専門家」になる |

# まとめ

## 金の流れ

```
発注者 100%
  ├─ 施工 90% → ゼネコン 10% → 下請け 80%
  ├─ 設計 5% → コンサル
  └─ 他 5%
```

## 儲けの構造

| 条件 | 儲かる | 儲からない |
|------|--------|-----------|
| ポジション | 元請け | 下請け |
| 専門性 | 高い | 低い |
| 資格 | ある | ない |
| 価格決定権 | ある | ない |

## 結論

**建設業で儲けるには「元請けになる」か「替えの効かない存在になる」しかない。**
