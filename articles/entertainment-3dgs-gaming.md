# 結論から言う

**3D Gaussian Splatting（3DGS）は、ゲーム・映画・VRの背景制作コストを1/5に削減する可能性がある。**

写真を撮るだけで、フォトリアルな3D空間が手に入る。UE5のNaniteで数ヶ月かけて作っていた背景が、数時間で完成する世界が来ている。

---

# CG制作の現状：コスト高騰の限界

AAA級ゲームの背景制作コストは年々上がっている。

- **UE5 Nanite/Lumen**の登場でフォトリアル品質は上がった
- だが、そのクオリティに見合うアセット制作に**数百人月**かかる
- 映画VFXも同様。Marvel級の作品で**背景1カットに数百万円**
- VRコンテンツは「作りたいけど予算がない」で頓挫するケースが多い

技術は進化した。だが**制作コストが追いついていない**。

ここに3DGSが入る。

---

# 3DGSとは（30秒で理解）

3D Gaussian Splattingは、**複数枚の写真から3D空間を再構成する技術**だ。

```
写真50〜200枚 → SfM（カメラ位置推定）→ 3DGS学習 → リアルタイム3D表示
```

従来のNeRFと違い、**明示的な3Dデータ（点群）** を持つ。だからゲームエンジンとの親和性が高い。

| 項目 | NeRF | 3DGS |
|------|------|------|
| 表現形式 | 暗黙的（MLP） | 明示的（Gaussian点群） |
| レンダリング | レイマーチング | ラスタライズ |
| リアルタイム | 困難 | **60+ FPS可能** |
| 編集性 | 低い | 高い |

**60FPS以上でリアルタイム描画できる**。これがエンタメ分野で使える最大の理由だ。

# エンタメでの活用シーン

## 1. ゲーム背景の実写3D化

ロケハンで撮影した写真から、そのままゲーム背景を生成する。

- 廃墟、森林、都市の路地裏を**スマホで撮影するだけ**
- 3DGS処理で数時間後にはゲーム内アセットとして使える
- **モデラー不要**。背景制作期間が数ヶ月→数日に短縮

## 2. 映画VFXの背景プレート3D化

ロケ地をドローンで撮影し、3DGSで3D背景プレートを生成。

- グリーンバック合成時の**カメラ自由度が格段に上がる**
- 実写ベースだから**ライティングの整合性**が自然
- Luma AIのようなサービスで既にプロダクション利用が始まっている

## 3. VR体験コンテンツの制作

観光地・美術館・歴史的建造物のVR化。

- 従来：3Dモデラーが数ヶ月かけて手作り → **予算1,000万円級**
- 3DGS：撮影1日 + 処理数時間 → **予算50万円以下**
- Meta Quest向けにリアルタイム表示も実現可能

## 4. バーチャルライブ・コンサート会場

実在の会場を3DGSでキャプチャし、バーチャル空間に再現。

- ライブ会場の雰囲気を**そのまま3D化**
- 座席からのビュー確認にも使える
- ファン向けの「聖地巡礼VR」コンテンツとして販売可能

## 5. メタバース空間の構築

メタバース空間の「リアルな場所」を大量に用意するには3DGSが最適。

- 1空間あたりの制作コストが**1/10以下**
- 実在の場所ベースだから「行ったことある感」がある
- UnityGaussianSplattingで**Unity上での統合実績あり**

# 従来手法との比較

| 項目 | フォトグラメトリ | LiDAR | **3DGS** |
|------|----------------|-------|----------|
| 入力 | 写真100〜500枚 | 専用機器 | **写真50〜200枚** |
| 機材コスト | カメラのみ | 100〜500万円 | **スマホでOK** |
| 処理時間 | 数時間〜数日 | リアルタイム | **数十分〜数時間** |
| 出力品質 | メッシュ（穴あり） | 点群（色なし） | **フォトリアル** |
| リアルタイム描画 | 要最適化 | 不可 | **60+ FPS** |
| データサイズ | 大（GB級） | 中 | **小（50〜200MB）** |
| 編集性 | 高い | 中 | 中〜高 |

**3DGSは「手軽さ」と「品質」のバランスが最も良い。**

# Unreal Engine / Unity との連携

## UE5との統合

- UE5 Nanite/Lumenと3DGSアセットの**ハイブリッド構成**が現実的
- 背景は3DGS、キャラクターは従来のメッシュモデルという使い分け
- NVIDIA Instant NGPの技術を活用したプラグインも登場

## Unityとの統合

- **UnityGaussianSplatting**プロジェクトが活発に開発中
- Unity上で3DGSデータを直接読み込み、リアルタイム表示
- URPおよびHDRPパイプライン対応

```
# 典型的なワークフロー
撮影 → COLMAP(SfM) → 3DGS学習 → PLY出力 → Unity/UE5読み込み → ゲーム統合
```

**課題**: 3DGSデータの動的ライティング対応はまだ発展途上。静的背景での利用が現時点のベストプラクティスだ。

# 商用利用の注意点

3DGSを商用プロダクトに組み込む際、**ライセンス問題**は避けて通れない。

| ラスタライザ | ライセンス | 商用利用 |
|-------------|-----------|---------|
| diff-gaussian-rasterization | Gaussian-Splatting License | **要契約（実質不可）** |
| gsplat | Apache 2.0 | 可能（ただし低速） |
| **HyperRasterizer** | **Apache 2.0** | **可能（DGR比1.45x高速）** |

オリジナルの3DGS実装は**Inria/Max-Planckライセンス**で、商用利用にはライセンス契約が必要。ゲームや映画に組み込む場合、これは大きなハードルになる。

**HyperRasterizer**はApache 2.0ライセンスで完全に独自実装。4169 FPSを達成しており、商用プロダクトにそのまま組み込める。

# まとめ

3DGSはエンタメ業界の3D制作を根本から変える技術だ。

- **ゲーム背景**: ロケハン写真からそのままアセット化
- **映画VFX**: ドローン撮影で3D背景プレート生成
- **VR/メタバース**: 制作コスト1/5〜1/10で実写品質の空間構築

技術的にはリアルタイム60FPS以上の描画が可能で、UE5/Unityとの統合も進んでいる。商用利用時のライセンス問題だけ注意すれば、今すぐ使える技術だ。
