# Claude Codeとは

## 概要

AnthropicがリリースしたCLIベースのAIコーディングアシスタント。

```
特徴:
├── ターミナルで動作（VSCode不要）
├── ファイルの読み書きができる
├── コマンド実行ができる
├── 長いコンテキストを保持
└── プロジェクト全体を理解
```

## 他ツールとの比較

| ツール | 特徴 | 得意なこと |
|--------|------|-----------|
| GitHub Copilot | エディタ統合 | 補完、小さな関数 |

| **Claude Code** | CLI、エージェント | **大規模変更、リファクタリング** |

**Claude Codeの強み: 複数ファイルにまたがる変更を一括で行える。**

# 具体的な使い方

## 1. 新機能の実装

```bash
# プロジェクトディレクトリで起動
claude

# 依頼
> ユーザー認証機能を追加して。
> 要件:
> - メールアドレスとパスワードでログイン
> - JWTトークンを使用
> - 既存のUserモデルを拡張
```

Claude Codeは:
1. 既存のコードを読む
2. 必要なファイルを特定
3. 実装コードを生成
4. ファイルに書き込む

**1つのプロンプトで複数ファイルを変更できる。**

## 2. バグ修正

```bash
> このエラーを修正して
> Error: Cannot read property 'id' of undefined
> at UserService.getUser (src/services/user.ts:42)
```

Claude Codeは:
1. エラーメッセージを解析
2. 該当ファイルを読む
3. 原因を特定
4. 修正を提案・実行

## 3. リファクタリング

```bash
> src/utils/ 以下のファイルを TypeScript に移行して
> 既存のテストが通るようにして
```

大規模な変更も一括で行える。

## 4. テスト生成

```bash
> src/services/user.ts のユニットテストを書いて
> Jest を使って
> エッジケースも含めて
```

## 5. ドキュメント生成

```bash
> このプロジェクトの README.md を生成して
> インストール方法、使い方、APIリファレンスを含めて
```

## 1. コンテキストを与える

```bash
# ❌ 悪い例

```

**具体的な指示 = 高品質な出力**

## 2. 段階的に依頼する

```bash
# ❌ 一度に全部
```

## 3. レビューを怠らない

```bash

2. セキュリティ上の問題はないか
3. パフォーマンスは問題ないか
4. 既存コードとの整合性はあるか
```

**AIは間違える。最終責任は人間。**

# 使ってはいけない場面

## 1. セキュリティクリティカルなコード

```
❌ 認証・認可のコアロジック
❌ 暗号化処理
❌ 決済処理

理由: 微妙なバグがセキュリティホールになる
対策: 人間が書き、AIにレビューさせる（逆パターン）
```

## 2. 機密情報を含むコード

```
❌ APIキーがハードコードされたファイル
❌ 顧客データを扱う処理
❌ 社内専用のビジネスロジック

理由: AIに送信されるリスク
対策: 機密部分をマスクして依頼
```

## 3. 理解せずに使う

```
❌ 「動いたからOK」
❌ 「AIが書いたから正しい」

✅ なぜこのコードなのか理解する
✅ 別の方法がないか検討する
```

# 設定のおすすめ

## CLAUDE.md（プロジェクト設定）

```markdown
# プロジェクト設定

## 技術スタック
- Next.js 14 (App Router)
- TypeScript
- Prisma + PostgreSQL
- Tailwind CSS

## コーディング規約
- 関数はアロー関数で統一
- コンポーネントは1ファイル1コンポーネント
- テストは同じディレクトリに .test.ts で配置

## よく使うコマンド
- npm run dev: 開発サーバー
- npm run test: テスト実行
- npm run lint: リント
```

プロジェクトルートに置いておくと、Claude Codeが自動で読み込む。
