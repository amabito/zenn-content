# 結論から言う

**3D Gaussian Splatting（3DGS）を使えば、教育コンテンツの3D化コストが従来の1/10になる。**

スマホで撮影するだけで、教室・実験室・博物館を丸ごと3D空間として再現できる。専用機材もVRゴーグルも不要。GIGAスクール構想で配布された1人1台の端末で、生徒がそのまま3D教材を体験できる時代が来た。

---

# 教育DXの現状と課題

文科省はGIGAスクール構想で全国の小中学生に1人1台端末を配布した。しかし、**端末はあるのにコンテンツが追いついていない**。

| 課題 | 現状 |
|------|------|
| 3D教材の制作コスト | 1コンテンツ100万円〜 |
| VR機器の導入費用 | 1台3〜10万円 × 人数分 |
| 教員のITリテラシー | 研修が追いつかない |
| オンライン授業の限界 | 2D画面では実験・実習が伝わらない |

コロナ禍でオンライン授業は普及したが、「画面越しの授業」の限界は明らかだ。理科の実験、美術館の見学、歴史遺跡の体験。**2Dでは伝えきれない学びが山ほどある。**

# 3DGSとは（30秒で理解）

```
従来の3Dスキャン:
  専用機材（数百万円）→ 点群処理 → メッシュ化 → テクスチャ → 完成
  期間: 数週間〜数ヶ月  コスト: 50〜300万円

3DGS:
  スマホで撮影（数分）→ 自動処理 → 3Dモデル完成
  期間: 数時間  コスト: ほぼゼロ
```

3DGSは写真から3D空間を再構築する技術だ。数十枚の写真をAIが解析し、**数百万個の「光の粒（Gaussian）」で空間を表現**する。

従来のメッシュベースの3Dモデルと違い、リアルタイムで描画でき、ブラウザ上でもヌルヌル動く。

# 教育での活用シーン

## 1. 博物館・美術館の3Dバーチャルツアー

**遠足に行けない学校でも、3Dで展示を体験できる。**

地方の学校にとって、都市部の博物館への遠足は交通費だけで1人数千円。3DGSなら、学芸員がスマホで展示室を撮影するだけで3Dツアーが完成する。生徒はタブレットで自由に歩き回り、展示物を好きな角度から観察できる。

## 2. 理科実験室の3D化（安全教育）

**危険な実験の事前シミュレーションに最適。**

化学実験室や工房をあらかじめ3D化しておけば、器具の配置や避難経路を事前に確認できる。「この薬品棚の横に立つな」「緊急シャワーはここ」といった安全教育が、実際の空間を使ってリアルに行える。

## 3. 建築・工学教育

**設計図だけでは理解できない空間を、3Dで体感。**

建築学科の学生が実際の建造物を3DGSでスキャンし、構造を分析する。橋梁、ビル、住宅。教科書の断面図ではなく、実物の3Dモデルで学ぶことで理解度が格段に上がる。

## 4. 歴史教育（遺跡・文化財の3D復元）

**教科書の写真1枚が、歩き回れる3D空間に変わる。**

城跡、古墳、寺社仏閣。文化財の3Dアーカイブは研究機関で進んでいるが、3DGSならスマホ1台で教員自身が作成できる。修学旅行の事前学習や、地域の文化財学習に活用できる。

## 5. オープンキャンパスの3D化

**来校できない受験生に、キャンパスを丸ごと届ける。**

大学・高校のオープンキャンパスを3D化すれば、遠方の受験生もブラウザで校内を歩ける。研究室、図書館、学食。写真やパンフレットでは伝わらない「空気感」を3Dで伝えられる。

# 課題と対策

## 1. 通信環境

3Dモデルのデータサイズは数十MB。校内Wi-Fiが脆弱な場合は表示が遅い。

**対策**: 圧縮技術の活用。3DGSは圧縮形式（.splat）に変換すれば元の1/5以下になる。ローカルキャッシュも有効。

## 2. 教員のITリテラシー

「3Dスキャン」と聞くと構えてしまう教員は多い。

**対策**: 操作は「スマホで撮影 → アップロード → 自動生成」の3ステップ。研修1回で十分習得できるレベルだ。

## 3. コンテンツの継続的な制作

1回作って終わりでは意味がない。年度ごとの更新が必要。

**対策**: 生徒自身にコンテンツ制作を任せる。探究学習の一環として「3Dアーカイブ部」を作れば、毎年コンテンツが蓄積されていく。
