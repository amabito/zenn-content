# 結論から言う

**建設コンサルタント業は「技術者の時間を売る」ビジネス。利益率は10-15%が限界。**

「建設コンサルタントって何やってるの？」「儲かるの？」

業界15年の経験から、この業界のビジネスモデルを解剖する。

**この記事で得られること:**
- 建設コンサルの仕事内容
- 収益構造と利益率
- 業界の課題と将来性

---

# 建設コンサルタントとは

## 定義

```
発注者（国・自治体）と建設会社の間に立ち、
計画・調査・設計・監理を行う技術者集団
```

## 位置づけ

```
発注者（国交省、自治体）
    ↓ 設計・調査業務を発注
建設コンサルタント ← この位置
    ↓ 設計図書を作成
ゼネコン・建設会社
    ↓ 施工
完成した構造物
```

**「モノを作る」のではなく「図面と計画を作る」のが仕事。**

# 収益構造

## 売上の内訳（典型的な中堅企業）

| 区分 | 割合 | 特徴 |
|------|------|------|
| 公共事業（国） | 40% | 単価高い、競争激しい |
| 公共事業（地方） | 35% | 地域密着、継続性あり |
| 民間事業 | 15% | 変動大、利益率高い |
| その他 | 10% | 維持管理、点検等 |

**売上の75%以上が公共事業依存。**

## 利益率

| 規模 | 売上高営業利益率 |
|------|-----------------|
| 大手 | 8〜12% |
| 中堅 | 5〜8% |
| 中小 | 2〜5% |
| 零細 | 0〜3% |

**製造業（3〜5%）より高いが、IT（15〜20%）よりは低い。**

# 受注形態

## プロポーザル（企画競争）

```
発注者: 「この課題を解決してください」
コンサル: 「こう解決します」（提案書提出）
評価: 技術力 + 価格
```

| 項目 | 配点（例） |
|------|----------|
| 技術提案 | 60点 |
| 実績・資格 | 20点 |
| 価格 | 20点 |

**技術力がモノを言う。大手有利。**

## 総合評価落札

```
評価値 = 技術評価点 ÷ 入札価格
```

技術も価格も重要。バランスが求められる。

## 価格競争入札

```
最低価格 = 落札
```

**測量や単純業務はこれ。利益が出ない。**

# コスト構造

## 固定費 vs 変動費

| 項目 | 割合 | 分類 |
|------|------|------|
| 人件費 | 55〜65% | 固定費 |
| 外注費 | 15〜25% | 変動費 |
| 経費（家賃等） | 10〜15% | 固定費 |
| その他 | 5〜10% | 混合 |

**人件費が過半数。人が辞めなければ利益が出る構造。**

## 技術者単価

| ランク | 日額単価 | 年収換算 |
|--------|---------|---------|
| 技師長 | 65,000円 | 1,625万円 |
| 主任技師 | 55,000円 | 1,375万円 |
| 技師A | 45,000円 | 1,125万円 |
| 技師B | 35,000円 | 875万円 |
| 技師C | 28,000円 | 700万円 |
| 技術員 | 22,000円 | 550万円 |

※国交省設計業務等標準積算基準（2025年度）

**単価は年収の約2.5倍。差額が会社の利益。**

# 業界構造

## 売上ランキング（2025年）

| 順位 | 企業名 | 売上高 |
|------|--------|--------|
| 1 | 日本工営 | 1,400億円 |
| 2 | 建設技術研究所 | 550億円 |
| 3 | パシフィックコンサルタンツ | 520億円 |
| 4 | オリエンタルコンサルタンツ | 500億円 |
| 5 | 八千代エンジニヤリング | 350億円 |

**上位5社で業界売上の20%を占める。**

## 業界の多層構造

```
大手（上位20社）
├── 直接受注: 大型プロジェクト
└── 元請けとして下請けに発注

中堅（21〜100位）
├── 直接受注: 中規模案件
├── 大手の下請け
└── 地方案件の元請け

中小（101位以下）
├── 大手・中堅の下請け
└── 地方小規模案件
```

## 参入障壁

| 障壁 | 内容 |
|------|------|
| 登録制度 | 建設コンサルタント登録が必要 |
| 資格要件 | 技術士・RCCM必須 |
| 実績 | 過去実績がないと入札できない |
| 信用 | 長年の取引関係 |

**新規参入は困難。既存プレイヤー有利。**

# 競争環境

## 競争要因

| 要因 | 重要度 | 内容 |
|------|--------|------|
| 技術力 | ◎ | 提案力、専門性 |
| 実績 | ◎ | 過去の類似業務経験 |
| 価格 | ○ | 競争入札では決定的 |
| 人脈 | ○ | 発注者との関係 |
| 地域性 | ○ | 地方では地元有利 |

## 大手 vs 中小

| 観点 | 大手 | 中小 |
|------|------|------|
| 技術力 | ◎ | △〜○ |

| 継続性 | ◎ | △ |

**中小は「特化」で勝負するしかない。**

# 収益向上の方法

## 方法1: 技術者の稼働率を上げる

```
理想: 稼働率85%以上
現実: 稼働率70%程度（多くの会社）

改善策:
- 繁閑の平準化
- 外注の活用
- 営業力強化
```

## 方法2: 技術者単価を上げる

```
技師C（28,000円）→ 技師A（45,000円）
日額 +17,000円 × 200日 = 年間 +340万円/人
```

**技術士を取らせることが最大の利益向上策。**

## 方法3: 外注費を適正化する

```
自社でやるべき業務: コア技術、提案
外注すべき業務: 単純作業、特殊技術
```

## 方法4: 民間比率を上げる

```
公共: 利益率低い、安定
民間: 利益率高い、変動大

バランス: 公共70% + 民間30%が理想
```

# リスク要因

## 景気リスク

```
公共事業予算 ∝ 売上
予算削減 → 売上減
```

**2010年代の「コンクリートから人へ」で業界は大打撃を受けた。**

## 人材リスク

```
技術士が辞める → 入札資格を失う → 売上激減
```

**キーマン依存のリスクが大きい。**

## 価格競争リスク

```
ダンピング → 利益率低下 → 品質低下 → 業界全体の衰退
```

## 技術革新リスク

```
AI/DXで業務が自動化 → 人手が不要に → ビジネスモデル崩壊
```

**ただし、これはチャンスでもある。**

# 未来の姿

## 2030年の建設コンサルタント

### 楽観シナリオ

```
- インフラ老朽化で需要増
- 防災・減災投資拡大
- DXで効率化、利益率向上
- 海外展開加速
```

### 悲観シナリオ

```
- 公共事業予算削減
- AIが設計を代替
- 価格競争激化
- 人材流出
```

## 生き残る会社の条件

| 条件 | 内容 |
|------|------|
| 専門性 | 特定分野でNo.1 |
| DX対応 | ICT/AIを使いこなす |
| 人材育成 | 若手が育つ環境 |
| 財務基盤 | 自己資本比率30%以上 |
| 多角化 | 公共依存からの脱却 |
