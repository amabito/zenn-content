# 1. PoC実行マニュアル（5日間）

## Day 1: 対象ライン選定

PoCの成否はライン選定で8割決まる。以下の4条件をすべて満たすラインを選ぶ。

| 条件 | 理由 | 具体例 |
|------|------|--------|
| 照明が安定している | 蛍光灯フリッカーや暗所は品質に直結 | 日勤帯で窓からの自然光がある組立エリア |
| 反射面が少ない | 鏡面仕上げの設備は3DGSが苦手 | 塗装ラインよりも組立ラインを優先 |
| 直近にレイアウト変更予定がある | PoC結果をすぐ業務に活かせる | 新設備導入予定のラインが最適 |
| ラインリーダーが協力的 | 現場の協力がないと撮影できない | 事前に趣旨を説明し合意を取る |

**選定NG例:** クリーンルーム（入室制限）、プレス工程（騒音・振動で撮影困難）、24時間稼働ライン（撮影時間が取れない）

## Day 2-3: 撮影

### 工場特有の撮影注意点

| 課題 | 対策 | 補足 |
|------|------|------|
| 蛍光灯フリッカー | シャッタースピード1/100s以下に設定（50Hz地域）、1/120s（60Hz地域） | スマホの場合はPro/マニュアルモードで設定 |
| 暗所（設備裏、配管下） | LEDワークライト2灯を左右45度から照射 | 影が1方向に偏ると3DGS品質が劣化する |
| 反射面 | 反射防止スプレー（3M Dulling Spray等）を一時的に噴霧 | 撮影後に拭き取り可能か事前確認 |
| 動く設備 | 撮影時はライン停止、コンベアもOFF | フォークリフトの通行も一時停止を依頼 |
| 床面の反射 | 光沢のあるエポキシ床は斜め45度から撮影 | 真上から撮ると天井照明が映り込む |

### 撮影手順

```
1. ライン全体の周回撮影（外周を歩いて動画30分）
   - 高さ: 目線（150cm）+ しゃがみ（80cm）の2周
   - 速度: 秒速30cm以下（ゆっくり歩く）
   - 重なり: 同じ場所を3方向以上からカバー

2. 設備個別の近接撮影（主要設備ごとに動画5分）
   - 設備を中心に360度周回
   - 操作パネル面は正面から追加撮影
   - 配管接続部は下から見上げる角度も追加

3. 天井・配管の撮影（動画10分）
   - スマホを上に向けてゆっくり歩く
   - 天井クレーン、ダクト、配管ラックをカバー

合計: 約60分の撮影で300-500フレームを抽出
```

## Day 4-5: 3DGS生成とビューア共有

```
1. フレーム抽出: ffmpeg -i video.mp4 -vf "fps=2" frames/%04d.jpg
2. COLMAP処理: 約2-4時間（500枚、GPU使用時）
3. 3DGS学習: 約1-2時間（30,000イテレーション）
4. 品質確認: HyperViewerでウォークスルー
5. 共有: PLYファイルをビューアURLで関係者に配布
```

## 成功基準

| KPI | 目標値 | 測定方法 |
|-----|--------|---------|
| 撮影時間 | 2時間以内（準備含む） | 実測 |
| 生成品質 | 設備の銘板が読める | 目視確認 |
| 3Dモデル精度 | 設備間距離の誤差5cm以内 | メジャーで実測と比較 |
| 関係者評価 | 5段階で4以上 | アンケート（5名以上） |
| レイアウト検討時間 | 従来比50%以上短縮 | 実際の検討会で比較 |

# 2. 撮影SOP（工場版）

## 設備タイプ別の撮影パターン

| 設備タイプ | 撮影パターン | 所要時間 | 枚数目安 | ポイント |
|-----------|------------|---------|---------|---------|
| プレス機 | 正面→側面→背面→上部、金型交換口は近接撮影 | 15分 | 80-120枚 | 油圧配管の接続部を重点撮影 |
| 組立ライン | ラインに沿って往復、ステーション毎に360度 | 30分 | 150-250枚 | 治具・工具の配置も漏れなく |
| クリーンルーム | ガウン着用、三脚固定で回転撮影、手持ちNG | 20分 | 100-150枚 | パーティクルカウンタ停止確認 |
| 倉庫・資材置場 | 通路を直線歩行、ラック正面は1棚ずつ | 20分 | 100-200枚 | 荷物移動は不要、現状のまま撮影 |

## 安全対策チェックリスト

撮影前に必ず確認する。1項目でも未対応なら撮影中止。

```markdown
[ ] ヘルメット着用（撮影者全員）
[ ] 安全靴着用（つま先保護付き）
[ ] 立入禁止区域の確認（赤テープ、柵の内側に入らない）
[ ] ライン停止の確認（主電源OFF、ロックアウト・タグアウト実施）
[ ] 所轄部門への撮影開始・終了連絡
[ ] 緊急時の避難経路確認（最寄りの非常口を2箇所把握）
```

## 撮影NGゾーン

以下のエリアでは3DGS撮影を行わない。

| ゾーン | 理由 | 代替手段 |
|--------|------|---------|
| 回転体近傍（旋盤、研削盤のチャック周辺） | 巻き込み事故リスク | ライン完全停止後に撮影 |
| 高温部（炉、溶接ロボット周辺） | やけどリスク、熱でスマホ故障 | 望遠レンズで離れて撮影 |
| レーザー加工機前 | 反射レーザーで目を損傷 | 安全カバー閉鎖状態で外観のみ |
| 薬品保管エリア | 有機溶剤の引火リスク | 防爆仕様カメラを使用 |

## 人物映り込み対策

| 対策 | 実施タイミング | 備考 |
|------|-------------|------|
| 操業停止時間に撮影 | 昼休み、シフト交代時、休日 | 最も確実 |
| 撮影エリアを一時封鎖 | 撮影中のみ | コーンとロープで区画 |
| 後処理でマスキング | 撮影後 | SAM2等でセグメンテーション、工数増 |

## 照明対策

| 照明環境 | 問題 | 対策 |
|---------|------|------|
| 蛍光灯のみ | フリッカー、色温度ばらつき | シャッタースピード固定、WB手動設定 |
| 天窓あり（混合光） | 時間帯で影の向きが変わる | 曇天日を選ぶ、または遮光カーテン |
| 暗所（設備内部） | ノイズ増加、特徴点不足 | LED投光器2灯、ISO上限1600 |
| 反射床（エポキシ塗装） | 照明映り込みで二重像 | 偏光フィルタ装着、斜め撮影 |

# 3. 品質基準設計

## 品質レベル定義

| ランク | 基準 | 用途 | 再撮影要否 |
|--------|------|------|-----------|
| A（優） | 設備銘板の文字が読める、配管径の目視判別可、色再現良好 | 設備台帳、保全記録、教育資料 | 不要 |
| B（良） | 設備全体形状が正確、主要部品の識別可、floater軽微 | レイアウト検討、遠隔監査 | 不要 |
| C（可） | 全体形状は把握可能だが細部不鮮明、色ずれあり | 簡易確認、概要把握 | 検討要 |
| D（不可） | 大きな歪み、欠損部分あり、floater多数 | 使用不可 | 再撮影必須 |

## 検収チェックリスト（15項目）

```markdown
【形状精度】
[ ] 1. 設備間距離の誤差が実測比5%以内
[ ] 2. 通路幅が実際の寸法と10cm以内の差
[ ] 3. 設備の高さ方向に大きな歪みがない

【視覚品質】
[ ] 4. floater（浮遊ゴミ）が全体の1%以下
[ ] 5. 色再現が実物と目視で一致
[ ] 6. テクスチャのブレ・ボケが許容範囲内

【カバレッジ】
[ ] 7. 対象エリアの床面が95%以上カバー
[ ] 8. 主要設備が全方向から視認可能
[ ] 9. 天井・配管が80%以上カバー

【操作性】
[ ] 10. ビューアで60FPS以上で表示可能
[ ] 11. ウォークスルーでカクつきがない
[ ] 12. ファイルサイズが500MB以下

【業務要件】
[ ] 13. 対象ラインの全ステーションが識別可能
[ ] 14. 安全通路・避難経路が確認可能
[ ] 15. 機密情報（図面、数値表示）が必要に応じてマスク済み
```

## リテイク判定基準

| 指標 | 合格 | 要改善 | リテイク |
|------|------|--------|---------|
| floater率 | 1%以下 | 1-3% | 3%超 |
| 欠損面積 | 5%以下 | 5-15% | 15%超 |
| 寸法誤差 | 5%以内 | 5-10% | 10%超 |
| 表示FPS | 60以上 | 30-60 | 30未満 |
| 関係者評価 | 4.0以上 | 3.0-4.0 | 3.0未満 |

## 経年変化への対応

| 頻度 | 対象 | トリガー |
|------|------|---------|
| 四半期 | 全ラインの定期スキャン | カレンダー固定（1,4,7,10月の第1週） |
| 随時 | レイアウト変更があったライン | 設備移設・新設の完了時 |
| 年次 | 全社マスターデータ更新 | 期初の棚卸しと同時実施 |
| 不定期 | 事故・災害後の現況記録 | インシデント発生時に即日撮影 |

# 5. 失敗パターンと対策

## パターン1: 機密情報流出

**状況:** クラウドサービスで3DGS生成したら、設備の制御パネルに表示された生産パラメータが高解像度で3Dモデルに残った。取引先に共有したモデルから数値が読み取れることが発覚。

**対策:**
- 撮影前にモニター画面をOFF、または遮蔽
- 処理はオンプレミス環境（HyperSplat等のOSSを自社GPU上で実行）
- 共有前に機密エリアをマスキング処理
- 社内ルール: 撮影対象に紙の図面・帳票が映らないことを確認

## パターン2: 現場の抵抗

**状況:** 「忙しいのに撮影のためにラインを止めろと？余計な仕事が増えるだけだ」と現場リーダーに拒否された。

**対策:**
- まず現場のメリットを示す（「レイアウト検討の立会い時間が半分になる」）
- 撮影は昼休みまたはシフト交代時に実施、操業への影響ゼロ
- 完成した3Dモデルを最初に現場に見せる（「これ、すごいですね」の反応を引き出す）
- 成功体験を社内報で発信し、他ラインからの自発的な依頼を促す

## パターン3: 品質ばらつき

**状況:** 担当者Aが撮影するとAランク品質だが、担当者Bだとフレームの動きが速くDランク。属人化して拡大できない。

**対策:**
- 撮影SOPを整備（本記事のSection 2を活用）
- 撮影者認定制度の導入（Level 1-3）
- 撮影直後に現場でプレビュー確認（ブレ・欠損を即座に検出）
- 動画撮影の場合、歩行速度をメトロノームアプリで制御（BPM=30で1歩ずつ）

## パターン4: ROI説明の失敗

**状況:** 「年間900万円削減」と説明したが、経営層から「その数字の根拠は？」と突っ込まれて答えられず、稟議が否決された。

**対策:**
- PoCで実測データを取る（実際の検討会で従来比何時間短縮できたか）
- 「人件費単価×削減時間×年間回数」で算出し、前提条件を明示
- 副次効果も数値化（出張削減、教育期間短縮、品質事故防止）
- 同業他社の事例があれば引用（業界誌、展示会情報）
- 小さな数字から始める: 「まず1ライン年間100万円削減を実証」

## パターン5: ベンダー依存

**状況:** 3DGS生成をベンダーに外注していたが、月50万円のランニングコストが膨らみ、内製化しようとしたらノウハウがなく移行できない。

**対策:**
- PoC段階から内製化を前提にツール選定（OSSベースを選ぶ）
- ベンダー利用時は「技術移転」を契約に含める
- 内製化タイミングの目安: 月間スキャン数が5回を超えたら
- 内製化移行スケジュール: ベンダー並走3ヶ月→段階的に内製比率を上げる

| 月間スキャン数 | 推奨 | 月額コスト目安 |
|-------------|------|-------------|
| 1-3回 | ベンダー外注 | 10-30万円 |
| 4-8回 | 内製+困難案件のみ外注 | 5-15万円+人件費 |
| 9回以上 | 完全内製 | 人件費のみ |
