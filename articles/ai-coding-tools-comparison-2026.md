## 世代別分類

### 第1世代：補完（Copilot）

```
[あなたがコードを書く]
      ↓
AIが次の1-2行を予測・提案
      ↓
[Tab で受け入れ]
```

**代表:** GitHub Copilot（オートコンプリート）

**特徴:**

- リアルタイム（タイプ中に提案）
- 短い単位（1行〜数行）
- 高速（遅延<100ms）

---

### 第2世代：チャット（ChatGPT・Claude）

```
[問題を自然言語で説明]
      ↓
AIがコード全体を生成
      ↓
[コピペ or 手動修正]
```

**代表:** ChatGPT、Claude（Webインターフェース）

**特徴:**

- 対話形式
- 中規模単位（関数〜ファイル）
- 説明・デバッグも可能

---

### 第3世代：エージェント（Cursor・Claude Code）

```
[タスクを指示]
      ↓
AIが自律的に実行:
  - ファイル検索
  - マルチファイル編集
  - テスト実行
  - デバッグ・修正
      ↓
[完了を確認]
```

**代表:** Cursor、Claude Code、Aider

**特徴:**

- 自律実行（人間は監視のみ）
- 大規模単位（プロジェクト全体）
- リポジトリ理解

## 3大ツール詳細比較

### GitHub Copilot

**概要:**

```
IDE統合型のAI補完ツール
Microsoft（OpenAI）製
2021年リリース、最も普及
```

| 項目 | 詳細 |
|------|------|
| **主な用途** | リアルタイムコード補完 |
| **対応エディタ** | VS Code, IntelliJ, Vim, Neovim等 |
| **モデル** | GPT-4ベース |
| **価格** | $10/月（個人）、$19/月（ビジネス） |
| **速度向上** | 55%高速化（実測） |

**得意なこと:**

- Boilerplateコード生成（import文、型定義等）
- 既存パターンの繰り返し
- ユニットテストのスケルトン

**苦手なこと:**

- 複数ファイルにまたがる変更
- 高度なアーキテクチャ判断
- 既存コードの大規模リファクタリング

**実装例:**

```typescript
// あなたが書く
function calculateTotalPrice(items: Item[]) {
  // Copilotが提案（Tabで受け入れ）
  return items.reduce((sum, item) => sum + item.price * item.quantity, 0);
}
```

**推奨ユーザー:**

- 企業エンジニア（予算承認が下りやすい）
- 定型作業が多い人
- IDE内で完結したい人

---

### Cursor

**概要:**

```
エージェント機能を持つVS Code派生エディタ
2023年急成長、フロントエンド界隈で人気
```

| 項目 | 詳細 |
|------|------|
| **主な用途** | マルチファイル編集・リファクタリング |
| **対応エディタ** | Cursor専用エディタ（VS Codeベース） |
| **モデル** | Claude Opus 4.5 / GPT-4o |
| **価格** | $20/月 |
| **コンテキスト** | 中規模（数万行） |

**得意なこと:**

- コンポーネント単位のリファクタリング（React等）
- 複数ファイルの一括修正
- デザインシステムの適用

**苦手なこと:**

- 超大規模プロジェクト（10万行以上）
- エディタ外のタスク（ターミナル操作等）
- CLI・バックエンド重視の開発

**実装例:**

```
[あなた]
"すべての.tsxファイルでボタンコンポーネントを新しいデザインシステムに移行して"

[Cursor]
- 50個のファイルを自動検索
- Button → DesignSystemButton に置き換え
- import文を更新
- 完了報告
```

**推奨ユーザー:**

- フロントエンドエンジニア
- React/Vue/Svelte開発者
- GUI操作が好きな人

---

### Claude Code

**概要:**

```
Anthropic公式のCLIツール
ターミナルベースのエージェント
2025年後半に注目度急上昇
```

| 項目 | 詳細 |
|------|------|
| **主な用途** | マルチステップの自律タスク実行 |
| **対応エディタ** | ターミナル（エディタ非依存） |
| **モデル** | Claude Opus 4.5 / Sonnet 4.5 |
| **価格** | $20/月（Claude Pro） |
| **コンテキスト** | 大規模（50k+ LOC、成功率75%） |

**得意なこと:**

- 超大規模リファクタリング（5万行以上）
- Git操作含む複雑なワークフロー
- ターミナルベースの自動化
- Skill・Hook・MCPによる拡張性

**苦手なこと:**

- リアルタイム補完（遅い）
- 初心者向け（学習曲線が急）
- GUI操作

**実装例:**

```bash
# ターミナルで指示
$ claude "プロジェクト全体でTypeScriptのエラーを修正し、テストを実行してコミットして"

# Claude Codeが実行:
1. tsc --noEmit でエラー検出
2. 50個のファイルを自動修正
3. npm test 実行
4. 失敗したテストを修正
5. git commit -m "fix: TypeScript errors"
```

**推奨ユーザー:**

- CUI派のエンジニア
- バックエンド・インフラ開発者
- 大規模コードベースを扱う人

## 開発スタイル別推奨ツール

```
推奨: Cursor + GitHub Copilot

```

### 2. バックエンド・CLI中心

```
推奨: Claude Code + Copilot

理由:
- Claude Codeでマルチファイル変更
- Copilotで日常的な補完
```

### 3. 初心者・学習中

```
推奨: GitHub Copilot + ChatGPT

理由:
- Copilotで実践的なコード学習
- ChatGPTで概念理解
```

### 4. 大規模リファクタリング

```
推奨: Claude Code 一択

理由:
- 5万行以上のコードベースに対応
- Git操作含む自動化
```

### 5. 企業・チーム開発

```
推奨: GitHub Copilot（全員） + Cursor（一部）

理由:
- Copilotは予算承認が下りやすい
- Cursorは特定タスクで追加導入
```

## 実装の注意点

### 1. セキュリティ

| ツール | データ送信 | 企業利用 |
|--------|-----------|---------|
| **GitHub Copilot** | コード断片 | Business版で制御可 |
| **Cursor** | ファイル全体 | 設定で制御可 |
| **Claude Code** | コマンド実行結果 | ローカル実行 |

**対策:**

```bash
# .gitignore に機密ファイルを追加
.env
credentials.json
*.key
```

### 2. 過信の危険性

AIが生成したコードは**必ずレビュー**。

| 問題 | 頻度 | 対策 |
|------|------|------|
| **セキュリティ脆弱性** | 中 | 静的解析ツール併用 |
| **パフォーマンス問題** | 高 | プロファイリング |
| **バグ** | 中 | テスト必須 |
