# 結論から言う

**大手と零細で10年目時点の年収差は300万円。資格を取れば逆転可能。**

「建設コンサルタントって稼げるの？」「大手と中小、どっちがいい？」

業界15年の経験から、求人票には載らないリアルな年収事情を暴露する。

**この記事で得られること:**
- 会社規模別の年収レンジ
- 年収を上げる3つの方法
- 転職市場の実態

# 資格と年収

## 技術士の威力

```
技術士なし: 600万円（10年目）
技術士あり: 800万円（10年目）
差額: +200万円/年
```

**技術士を取れば、年収200万円アップ。**

生涯賃金で考えると:
```
30歳で取得 → 定年まで30年
200万 × 30年 = 6,000万円
```

## 資格別の年収上乗せ

| 資格 | 上乗せ額（目安） |
|------|----------------|
| 技術士 | +150〜250万 |
| RCCM | +50〜100万 |
| 一級土木施工管理技士 | +30〜50万 |
| 測量士 | +20〜30万 |

**技術士とRCCMの両方を持つと、年収100万円以上の差。**

# 年収の上げ方

## 方法1: 資格を取る（王道）

```
25歳: 入社
28歳: RCCM取得 (+50万)
32歳: 技術士取得 (+200万)
35歳: 管理技術者として独り立ち
```

**最も確実なルート。**

## 方法2: 転職する

| 転職パターン | 年収変動 |
|------------|---------|
| 中小→大手 | +100〜200万 |
| 大手→大手 | +50〜100万 |
| 大手→中小 | -50〜0万（役職次第） |
| 民間→公務員 | -100〜0万 |

**技術士を持っていると、転職市場で有利。**

## 方法3: 専門性を磨く

```
汎用技術者: 替えが効く → 年収据え置き
専門技術者: 希少性あり → 年収アップ
```

希少性が高い分野:
- インフラ長寿命化
- 防災・減災
- 環境アセスメント
- ICT/DX推進

## 方法4: 独立する

| 形態 | 年収レンジ | リスク |
|------|-----------|--------|
| フリーランス | 400〜1,500万 | 高 |
| 法人設立 | 500〜2,000万 | 高 |
| 大手と業務委託 | 600〜1,000万 | 中 |

**成功すれば2,000万円も可能。失敗すれば400万円以下。**

# 年収の現実

## 残業込みの話

上記の年収は**残業込み**。

| 時期 | 残業時間 |
|------|---------|
| 繁忙期（1-3月） | 80〜120時間 |
| 通常期 | 20〜40時間 |
| 閑散期 | 0〜20時間 |

年間残業時間: 400〜600時間
残業代: 年収の15〜25%

**基本給だけだと、表示額より15〜25%低い。**

## 賞与の実態

| 規模 | 賞与月数 |

| 大手 | 4〜6ヶ月 |
| 中小 | 2〜4ヶ月 |

**業績連動が多く、不況時は減額リスクあり。**

# 就活生・転職者へ

## 大手に入るべきか

| 観点 | 大手 | 中小 |
|------|------|------|
| 年収 | ◎ | △ |
| 安定性 | ◎ | △〜○ |
| 成長環境 | ◎ | ○ |
| 裁量 | △ | ◎ |
| 独立準備 | △ | ◎ |

**まずは大手で修行し、中堅で転職 or 独立がベター。**

## 狙い目の会社

1. **大手の子会社**: 待遇は親会社並み、競争は緩い
2. **地方の有力企業**: 地域トップなら待遇良好
3. **特定分野特化型**: 専門性が身につく

## 避けるべき会社

1. **測量単価で勝負する会社**: 価格競争で疲弊
2. **技術者がいない会社**: 成長できない
3. **技術士ゼロの会社**: 案件を取れない
