# 年収帯別スキルマップ

## 400-600万（ジュニア）

```
必須スキル:
├── 言語1つをある程度使える
├── Git/GitHubの基本操作
├── 基本的なインフラ知識
└── コードレビューを受けられる

この層を抜けるには:
→ 「任せられる」レベルになる
→ 1人で機能を実装〜デプロイできる
```

## 600-800万（ミドル）

```
必須スキル:
├── 設計ができる（DB設計、API設計）
├── チームでの開発経験
├── パフォーマンス改善の経験
└── 後輩の指導経験

この層を抜けるには:
→ 「専門性」または「マネジメント」
→ どちらかに振り切る
```

## 800-1000万（シニア）

```
必須スキル（技術特化）:
├── 特定領域で社内トップレベル
├── 技術選定の経験
├── 大規模システムの経験
└── 外部発信（登壇、ブログ）

必須スキル（マネジメント）:
├── 5人以上のチームリード経験
├── 採用面接の経験
├── プロジェクト管理経験
└── 評価・フィードバックの経験
```

## 1000万以上（スペシャリスト/マネージャー）

```
技術特化:
├── 業界で名前が知られている
├── OSS貢献 or 論文
├── 難問を解決した実績
└── 「○○といえばこの人」

マネジメント:
├── 複数チームの統括
├── 予算管理
├── 事業計画への関与
└── 採用の最終判断
```

# 転職で年収を上げる交渉術

## 原則: 先に金額を言わない

```
面接官: 「希望年収は？」

❌ 「800万円です」
→ 800万で決まる（それ以上にならない）

✅ 「現職は700万ですが、御社の水準に合わせたいと思います」
→ 会社の予算に応じて提示される（900万かも）
```

## 複数内定を取る

```
A社: 850万で内定
B社: 面接中

B社に伝える:
「他社から850万でオファーをいただいています」
→ B社が本気なら900万以上を提示

A社に伝える:
「他社からより良い条件の提示がありました」
→ A社が本気なら880万に上げる可能性
```

**競争原理を働かせる。**

## 年収交渉のタイミング

```
❌ 一次面接で年収の話をする
❌ 最終面接で初めて年収の話をする

✅ 二次面接以降で「希望年収帯」を確認
✅ オファー面談で具体的な交渉
```

## 交渉で使えるフレーズ

```
「現職では○○の経験があり、御社でも即戦力として貢献できると考えています」

「他社からは○○万円のオファーをいただいていますが、
 御社の事業に魅力を感じており、条件面で前向きにご検討いただけると嬉しいです」

「基本給での調整が難しければ、
 サインボーナスや株式報酬での調整は可能でしょうか」
```

# 副業で月20万稼ぐ案件獲得法

## 案件獲得の3つのチャネル

| チャネル | 単価 | 獲得難易度 | 継続性 |
|---------|------|-----------|--------|
| 知人紹介 | 高 | 低（信頼があれば） | 高 |
| SNS/ブログ経由 | 中〜高 | 中 | 中 |
| クラウドソーシング | 低 | 高（競争激しい） | 低 |

**優先順位: 知人紹介 > SNS > クラウドソーシング**

## 知人紹介を増やす方法

```
1. 勉強会・イベントに参加（月2回以上）
2. 「副業探してます」と公言する
3. 小さな相談に無料で乗る
4. 納品後に「紹介してください」と伝える
```

## SNS/ブログからの案件獲得

```
技術ブログ記事
  ↓
「この記事を書いた人に依頼したい」
  ↓
問い合わせフォーム or DMで連絡
  ↓
案件化

ポイント: 記事の最後に「お仕事の依頼はDMへ」と書く
```

## 単価の上げ方

```
初案件: 時給3000円（実績作り）
2-3件目: 時給4000円
5件目以降: 時給5000円以上

「前回の案件では時給○○円でしたので、
 今回は○○円でお願いできればと思います」
```

## 月20万の具体例

```
案件A: Webアプリ改修（月10時間 × 5000円 = 5万円）
案件B: データ分析（月15時間 × 5000円 = 7.5万円）
案件C: 技術顧問（月5時間 × 15000円 = 7.5万円）
合計: 20万円
```

# 職務経歴書テンプレート

## 年収800万以上を狙う場合の書き方

```markdown
# 職務経歴書

## 要約（3行で）
- バックエンドエンジニアとして5年の経験
- 月間1000万PVのサービスの設計・開発をリード
- Go/Python/AWSを用いた大規模システム構築が得意

## 職務経歴

### 株式会社〇〇（2020年4月〜現在）

**プロジェクト1: ECサイトリニューアル（2023年）**

- 役割: テックリード（5名チーム）
- 技術: Go, PostgreSQL, AWS (ECS, RDS, ElastiCache)
- 成果:
  - レスポンスタイムを500ms→100msに改善（5倍高速化）
  - 売上15%向上に貢献（ページ離脱率低下）
  - CI/CD整備でデプロイ時間を1時間→10分に短縮

**ポイント:**
- 数字を入れる（5倍、15%、1時間→10分）
- ビジネス成果に紐づける（売上向上）
- 役割を明確に（テックリード）
```

## NG例

```markdown
❌ 「様々なプロジェクトに参加」
→ 具体性がない

❌ 「チームで開発を行った」
→ あなたの貢献が見えない

❌ 「新技術を導入した」
→ 何を、なぜ、どう導入したか不明
```

## 差別化ポイント

```
✅ 技術ブログURL
✅ GitHub URL
✅ 登壇資料URL
✅ OSS貢献

「経歴書に書ききれない実績はこちら」とURLを載せる
```

# 年収交渉の実例

## 実例1: 700万→900万

```
状況:
- 現職700万、転職活動中
- A社から850万でオファー
- B社から900万でオファー

交渉:
A社に「他社から900万の提示がある」と伝える
→ A社が「920万まで出せます」と回答
→ A社に入社

ポイント: 嘘は言わない、事実を伝えるだけ
```

## 実例2: 600万→800万（職種変更込み）

```
状況:
- SIer勤務600万
- Web系自社開発に転職希望

交渉:
「経験は浅いですが、個人開発で○○を作りました」
「技術ブログで月間1万PVあります」
「御社の技術スタックは独学で習得済みです」
→ ポテンシャル採用で800万

ポイント: 経験不足を「自走力」でカバー
```

# 1000万到達のタイムライン

## パターン1: 転職メイン（3-5年）

```
Year 0: 500万（現職）
Year 1: 650万（転職1回目）
Year 2: 750万（昇給）
Year 3: 900万（転職2回目）
Year 4: 1000万（昇給 or 転職3回目）
```

## パターン2: 副業メイン（2-3年）

```
Year 0: 500万（本業のみ）
Year 1: 500万 + 150万（副業開始）= 650万
Year 2: 550万 + 300万（副業拡大）= 850万
Year 3: 600万 + 400万（副業安定）= 1000万
```

## パターン3: フリーランス（1-2年）

```
Year 0: 500万（正社員）
Year 1: 900万（フリーランス転向、月75万）
Year 2: 1200万（単価アップ、月100万）

リスク: 案件途切れ、社会保険自己負担
```

# まとめ

| 年収帯 | 必要なこと |
|--------|-----------|
| 〜600万 | 基礎スキル、1人で実装できる |
| 600-800万 | 設計力、チーム開発 |
| 800-1000万 | 専門性 or マネジメント |
| 1000万〜 | 業界での知名度、希少性 |

| 年収を上げる方法 | 難易度 | 効果 |
|-----------------|--------|------|
| 転職 | 中 | +100〜200万/回 |
| 副業 | 中 | +100〜400万/年 |
| 昇給 | 低 | +20〜50万/年 |
| フリーランス | 高 | +300〜500万/年 |

**1000万は「正しい戦略」+「行動量」で到達できる。**
