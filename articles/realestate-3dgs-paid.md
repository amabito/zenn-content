# 1. 撮影SOP（標準作業手順書）

## 物件タイプ別スペック

| 物件タイプ | 撮影時間 | 撮影枚数 | 部屋数目安 | 難易度 |
|-----------|---------|---------|-----------|--------|
| ワンルーム/1K | 15分 | 80枚 | 1〜2室 | 低 |
| ファミリー（2LDK〜3LDK） | 25分 | 150枚 | 4〜6室 | 中 |
| 戸建て（2階建て） | 40分 | 250枚 | 7〜10室+外観 | 高 |

## 撮影順序テンプレート

どの物件タイプでも、以下の順序を守ることで撮影漏れを防ぐ。

```
玄関 → 廊下 → LDK → キッチン → 各居室（奥から手前へ）
→ 洗面所 → 浴室 → トイレ → バルコニー → 収納内部 → 外観
```

### 部屋ごとの撮影パターン

| 部屋 | 撮影ポイント | 枚数目安 | 注意点 |
|------|-------------|---------|--------|
| 玄関 | 入口→室内方向、靴箱、天井 | 8枚 | ドアを開けた状態と閉めた状態の両方 |
| LDK | 四隅から対角線方向、窓際、天井 | 25枚 | 最も重要。80%オーバーラップ必須 |
| キッチン | 正面、左右、上部収納、シンク | 12枚 | 照明を全点灯。金属反射に注意 |
| 居室 | 四隅から対角線方向、窓、クローゼット内 | 15枚/室 | クローゼットは扉を開けて撮影 |
| 洗面所 | 正面、左右、鏡は斜め45度から | 8枚 | **鏡に自分が映らない角度で** |
| 浴室 | 入口から、奥から、天井 | 8枚 | 水滴を拭き取ってから撮影 |
| トイレ | 入口から、正面、左右 | 6枚 | 便座は閉じた状態 |
| バルコニー | 室内から外、外から室内、眺望 | 10枚 | 眺望は重要な訴求ポイント |
| 外観 | 四方+エントランス | 15枚 | 戸建て限定。隣家が映りすぎないよう注意 |

## NG例とOK例

| 項目 | NG | OK | 影響 |
|------|----|----|------|
| 明るさ | 自然光のみ、影が強い | 全照明ON + カーテン開放 | 暗部のGaussianにノイズ発生 |
| ブレ | 手持ちで急いで移動 | 三脚 or ジンバル使用 | ブレ画像はCOLMAP失敗の主因 |
| オーバーラップ | 50%以下（飛び飛び） | 80%以上（少しずつ移動） | 不足するとfloater大量発生 |
| 高さ | 見下ろし・見上げ混在 | 目線高さ（120〜140cm）で統一 | 高さ不統一は3D再構成の精度低下 |
| 散らかり | 私物・ゴミが映る | 清掃・片付け後に撮影 | 3Dモデルに永久に残る |

## 季節・天候別の注意点

| 条件 | 注意点 | 対策 |
|------|--------|------|
| 晴天・直射日光 | 窓から強い光、影のコントラスト大 | レースカーテンで拡散、撮影は午前10時〜午後2時を避ける |
| 曇天 | 均一な光で撮影しやすい | **最適な撮影日和**。積極的に選ぶ |
| 雨天 | 窓の水滴、暗い | 全照明ON、窓は閉めて水滴を拭く |
| 夏（冷房） | 結露なし、日差し強い | 早朝 or 夕方推奨 |
| 冬（暖房） | 窓の結露 | 撮影前に換気して結露を除去 |

# 2. 品質管理フロー

外注や複数担当者での運用では、品質のバラつきが最大のリスクになる。以下の基準で統一する。

## 品質基準

| レベル | 定義 | 判定 |
|--------|------|------|
| A（優良） | floaterなし、色味均一、全部屋網羅、自由視点で違和感なし | 即納品 |
| B（合格） | 軽微なfloater5個以下、色味のズレが軽微 | 手動除去後に納品 |
| C（要リテイク） | floater多数、部屋の欠落、色味の大幅なズレ | 差し戻し |

## 検収チェックリスト（10項目）

外注先からの納品物を検収する際に使用する。**7項目以上合格で検収OK。**

| # | 検収項目 | 基準 | 合否 |
|---|---------|------|------|
| 1 | 全部屋が3Dモデルに含まれている | 間取り図と照合 | [ ] |
| 2 | Floater（浮遊物）がない | 目視で確認、5個以下ならB判定 | [ ] |
| 3 | 色味が実物と一致している | 壁の白、フローリングの色を目視確認 | [ ] |
| 4 | 窓の外が破綻していない | 窓際で視点を動かして確認 | [ ] |
| 5 | 鏡・ガラス面の破綻が許容範囲内 | 完全な再現は不要、目立つ歪みがないこと | [ ] |
| 6 | 自由視点で移動しても違和感がない | 玄関→LDK→各部屋を一筆書きで移動 | [ ] |
| 7 | ファイルサイズが適正 | ワンルーム: 30〜80MB、ファミリー: 50〜150MB | [ ] |
| 8 | 読み込み速度が5秒以内 | ビューアでの初期表示時間 | [ ] |
| 9 | モバイル表示に問題がない | スマホブラウザで確認 | [ ] |
| 10 | メタデータ（物件名、撮影日）が正確 | ファイル名・タグを確認 | [ ] |

## リテイク基準と差し戻しフロー

```
納品 → 検収チェック(10項目) → 7項目以上合格？
├── YES → 納品承認 → 顧客公開
└── NO → 差し戻しレポート作成 → 外注先に再撮影/再処理を依頼
         └── 再納品 → 再検収 → 2回目もNGなら外注先変更を検討
```

**差し戻しレポートに含める情報:**
- NG項目の番号と具体的な問題箇所（スクリーンショット添付）
- リテイク期限（通常3営業日以内）
- 合格基準の再確認

## iframe埋め込みの技術手順

### 1. ビューアをホスティング

```
自社サーバー or CDN
└── viewer/
    ├── index.html      # ビューアHTML
    ├── splat-viewer.js # レンダラ
    └── models/
        └── property_001.ply  # 物件データ
```

### 2. 埋め込みURL生成

```
https://viewer.example.com/?model=property_001&autoplay=1
```

パラメータ例:
- `model`: 物件ID
- `autoplay`: 自動回転ON/OFF
- `ui`: ナビゲーションUI表示

### 3. ポータルサイトへの登録

SUUMOの場合:
```
物件登録画面 → 「バーチャル内見URL」欄に上記URLを入力
```

HOME'Sの場合:
```
物件登録画面 → 「VR/パノラマURL」欄に上記URLを入力
```

# 5. トラブルシューティング

## 反射問題（鏡、窓ガラス、フローリング）

**症状:** 鏡に撮影者が映る、窓ガラスに周囲が反射、フローリングがギラつく。

| 対象 | 原因 | 対策 |
|------|------|------|
| 鏡 | 正面から撮影すると撮影者が映る | **斜め45度から撮影**。浴室の鏡は曇り止めスプレーで曇らせる |
| 窓ガラス | 室内照明の反射 | カーテンを開けて外光を優先。夜間撮影は避ける |
| フローリング | ワックスの光沢が反射 | 撮影角度を低くしすぎない（120cm以上）。偏光フィルター使用も有効 |
| ステンレス | キッチンのシンク、蛇口 | 完全な対策は困難。**撮影角度を変えて複数枚撮り**、3DGS側で平均化 |

## 暗い物件

**症状:** 北向き物件、地下、窓が小さい物件で3Dモデルが暗くノイズが多い。

**対策:**

| 方法 | コスト | 効果 |
|------|--------|------|
| 全照明ON（基本） | 0円 | 必須 |
| ポータブルLEDライト持参 | 3,000円 | 暗い部屋に効果大 |
| スマホの露出補正を+0.5〜+1.0 | 0円 | 全体的に明るくなるが白飛び注意 |
| 撮影後のヒストグラム補正 | 0円 | ソフトウェア処理で明るさ均一化 |

**注意:** 暗い物件は撮影枚数を1.5倍に増やす。暗所ではCOLMAPの特徴点検出精度が下がるため。

## 狭い物件

**症状:** ワンルームや狭小住宅で、十分なオーバーラップが確保できない。

**対策:**
- **広角レンズアタッチメント**（スマホ用、2,000〜5,000円）で画角を拡大
- **撮影位置を部屋の隅に固定**し、回転撮影で360度カバー
- 通常の移動撮影に加えて、**上方向（天井方向）の撮影を追加**
- 目安: 6畳以下の部屋は隅から対角4方向 + 中央から4方向 = 8ポジション

## 顧客クレーム対応：「実物と違う」

3DGSの品質が高いゆえのクレーム。「3Dで見た印象と実物が違う」という声への対策。

| クレーム内容 | 原因 | 予防策 |
|-------------|------|--------|
| 「思ったより狭い」 | 広角撮影による歪み | 標準画角で撮影、物件情報に専有面積を明記 |
| 「色が違う」 | モニターの色温度差 | 撮影時にカラーチャートを1枚撮影し色基準を記録 |
| 「日当たりが違う」 | 撮影時間帯による | 撮影日時を物件情報に記載、「撮影時の状況です」と注記 |
| 「周辺環境が分からない」 | 室内のみ撮影 | バルコニーからの眺望、エントランス、周辺写真を追加 |

**免責文テンプレート:**
```
※3Dバーチャル内見は撮影時の状況を再現したものです。
家具・照明の配置、日当たり等は実際と異なる場合があります。
正確な情報は担当者にお問い合わせください。
```

この免責文を3Dビューアの下部に常時表示することで、クレームリスクを大幅に軽減できる。
