# 3DGS導入の具体的手順

## ステップ1: 撮影（15分/物件）

```
必要機材: スマホ（iPhone 12以降推奨）
撮影枚数: 100〜200枚
撮影時間: 15分/物件
```

### 撮影のコツ

| ポイント | 良い例 | 悪い例 |
|----------|--------|--------|
| 照明 | 全照明ON | 自然光のみ |
| オーバーラップ | 80%重複 | 飛び飛び |
| 高さ | 目線の高さ | 上から見下ろす |
| 動き | ゆっくり移動 | 急いで撮影 |

## ステップ2: 処理（30分〜2時間）

```
アップロード → 自動処理 → 3Dモデル完成
```

SaaSを使えば、専門知識不要。

## ステップ3: 公開・共有

```
Webサイト埋め込み: iframeタグをコピペ
顧客への共有: URLを送るだけ
社内共有: 営業ツールに組み込み
```

# 注意点

## 注意1: 全物件に導入する必要はない

```
優先度高: 高単価物件、遠方顧客が多い物件
優先度低: 低単価物件、近隣顧客中心
```

## 注意2: 撮影品質が命

```
NG: 散らかった状態、照明暗い
OK: 整理整頓、全照明ON

「ホームステージング」と同じ発想。
```

## 注意3: 既存ワークフローとの統合

```
物件登録時に撮影フローを組み込む
└── 撮影 → アップロード → 物件情報に紐付け
```
