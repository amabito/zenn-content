# 結論から言う

**エンジニア1年目で年収1000万は可能。ただし「運」と「戦略」の両方が必要。**

「1年目で1000万？嘘でしょ」

そう思うのが普通だ。私も最初はそう思っていた。

この記事では、実際に1年目で1000万を超えた経緯と、再現可能な部分・不可能な部分を正直に解説する。

**この記事で得られること:**
- 1年目1000万の具体的な内訳
- 再現可能な戦略と、運だった部分
- 年収を上げるための具体的なアクション

---

# 私のスペック（当時）

## 前職
- 建設コンサルタント（非IT）
- 年収450万
- プログラミングは趣味レベル

## 転職時
- 独学でPython/機械学習を習得（1年）
- 個人開発でWebアプリ公開
- 技術ブログ50記事

**ポイント: 完全未経験ではなく「独学で実績を作った」状態。**

---

# 1年目の収入内訳

## 年収1,080万の構成

| 項目 | 金額 | 割合 |
|------|------|------|
| 本業（正社員） | 650万 | 60% |
| 副業（受託開発） | 280万 | 26% |
| 副業（技術ブログ） | 120万 | 11% |
| その他（登壇謝礼等） | 30万 | 3% |

**「年収」の定義を広げれば1000万は達成しやすい。**

純粋に正社員の給与だけで1000万は、1年目ではほぼ不可能（外資Big Tech除く）。

---

# 戦略だった部分（再現可能）

## 1. 「掛け算」のスキル選択

```
プログラミング × 建設業界知識 = 希少人材
```

単体では普通でも、掛け算で希少になる。

| 組み合わせ | 希少性 | 需要 |
|-----------|--------|------|
| Python × 金融知識 | 高 | 高 |
| ML × 製造業知識 | 高 | 高 |
| Web × 医療知識 | 高 | 中 |
| プログラミング単体 | 低 | 高 |

**前職の経験を「負債」ではなく「資産」にする。**

## 2. 発信による信頼構築

```
技術ブログ50記事
  ↓
「この人は本気だ」という証明
  ↓
未経験でも採用
  ↓
副業の依頼も来る
```

ブログは「実績がない人の実績」になる。

## 3. 副業を最初から想定

```
転職時の条件:
- 副業OK
- リモートワーク可
- 残業少なめ

年収よりも「時間の確保」を優先
```

本業650万でも、副業400万で計1050万。

---

# 運だった部分（再現困難）

## 1. タイミング

2024年、AI/ML人材の需要がピーク。建設DXの波も来ていた。

**今同じことをしても同じ結果になるとは限らない。**

## 2. 最初の副業案件

知人の紹介で月20万の案件を獲得。これがなければ副業収入はもっと低かった。

## 3. 体力

本業 + 副業 + ブログ執筆を1年間継続。体調を崩さなかったのは運。

---

# 再現するための具体的アクション

## Step 1: スキルの掛け算を設計する

```
あなたの前職/現職の知識 × プログラミング = ?

例:
- 経理 × Python = 経理自動化エンジニア
- 営業 × データ分析 = セールステックエンジニア
- 製造 × IoT = スマートファクトリーエンジニア
```

## Step 2: 発信を始める（今日から）

| 発信手段 | 目的 |
|---------|------|
| Zenn/Qiita | 技術力の証明 |
| X (Twitter) | 人脈形成 |
| GitHub | ポートフォリオ |

**週1記事 × 1年 = 50記事。これが最低ライン。**

## Step 3: 副業OKの会社を選ぶ

```
❌ 年収800万、副業禁止
✅ 年収600万、副業OK

長期的には後者が勝つ
```

# よくある質問

## Q: 未経験からでも可能？

A: 「完全未経験」は厳しい。最低でも以下が必要:
- 実務で使えるレベルのスキル（独学OK）
- 公開できるポートフォリオ
- 技術的なアウトプット（ブログ、OSS等）

## Q: 何歳まで可能？

A: 年齢より「掛け算できる経験があるか」が重要。むしろ30代以降の方が前職経験を活かしやすい。

## Q: 副業なしで1000万は？

A: 1年目では外資Big Tech以外ほぼ不可能。3-5年目なら国内企業でも可能。

# 注意点

## 税金を忘れるな

```
年収1080万（税引前）
  - 所得税・住民税: 約250万
  - 社会保険料: 約100万
  = 手取り: 約730万
```

**額面の7割が手取り。**

## 持続可能性

1年目の働き方を10年続けるのは無理。副業は徐々に「仕組み化」していく必要がある。

# まとめ

| 項目 | 内容 |
|------|------|
| 1年目1000万 | 可能（副業込み） |
| 再現性 | 戦略部分は高い、運部分は低い |
| 必須条件 | スキルの掛け算、発信、副業OK |
| 所要期間 | 準備1年 + 転職後1年 |

**「1年目で1000万」は目標ではなく結果。本質は「希少性を作る」こと。**
