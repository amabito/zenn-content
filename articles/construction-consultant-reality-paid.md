# Part 4: 技術的ノウハウ

## 撮影のコツ

### 良い撮影

| 項目 | 推奨 |
|------|------|
| 重複率 | 80%以上 |
| 撮影枚数 | 100〜300枚（1,000㎡あたり） |
| 天候 | 曇り推奨（影が少ない） |
| 時間帯 | 早朝または夕方 |
| 高度 | 対象物の1.5〜2倍の距離 |

### 避けるべき条件

| 条件 | 理由 | 対策 |
|------|------|------|
| 強い日差し | 影が濃くなりノイズ増加 | 曇りの日を選ぶ |
| 反射面 | ガラス、水面は苦手 | 偏光フィルター使用 |
| 動く物体 | floater発生 | 早朝撮影、マスク処理 |
| 単調なテクスチャ | 特徴点が取れない | 近接撮影を追加 |

## よくある失敗と対策

### 失敗1: floater（浮遊ノイズ）

**症状:** 空中に謎の物体が浮いている

**原因:**
- 撮影時に動いた物体（人、車）
- 反射光
- 撮影角度の不足

**対策:**
```python
# floater除去の基本
# 近傍密度が低いGaussianを削除

from sklearn.neighbors import NearestNeighbors

def remove_floaters(points, k=20, threshold=0.1):
    nbrs = NearestNeighbors(n_neighbors=k).fit(points)
    distances, _ = nbrs.kneighbors(points)
    mean_dist = distances[:, 1:].mean(axis=1)
    mask = mean_dist < threshold
    return points[mask]
```

### 失敗2: スケールのずれ

**症状:** 3Dモデルのスケールが実寸と合わない

**原因:** 3DGSはスケールレス

**対策:**
1. GCP（基準点）を3点以上設置
2. 既知の寸法物（メジャー、基準尺）を写り込ませる
3. 後処理でスケール補正

```python
# スケール補正
known_distance = 10.0  # 実際の距離（m）
measured_distance = 8.5  # 3Dモデル上の距離

scale_factor = known_distance / measured_distance
# 全座標にscale_factorを乗算
```

### 失敗3: 色が濃い/薄い

**症状:** 全体的に彩度が高すぎる/低すぎる

**原因:** 露出設定のばらつき、カラーマネジメント不足

**対策:**
```python
# 彩度の正規化
import cv2
import numpy as np

def normalize_saturation(image, target_saturation=0.5):
    hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)
    current_saturation = hsv[:, :, 1].mean() / 255.0
    scale = target_saturation / current_saturation
    hsv[:, :, 1] = np.clip(hsv[:, :, 1] * scale, 0, 255)
    return cv2.cvtColor(hsv, cv2.COLOR_HSV2BGR)
```
