# 結論から言う

**RTX 5090はRTX 4090比で1.5〜2倍の性能向上。**

| 項目 | RTX 4090 | RTX 5090 | 向上率 |
|------|----------|----------|--------|
| VRAM | 24GB | 32GB | +33% |
| メモリ帯域 | 1008 GB/s | 1792 GB/s | +78% |
| FP32演算 | 82.6 TFLOPS | 105 TFLOPS | +27% |
| 実測（3DGS） | 2870 FPS | 4169 FPS | +45% |

この記事では、実際のワークロードでの比較結果を解説する。

# ベンチマーク結果

## 3D Gaussian Splatting

**テスト条件:**
- 解像度: 800x600
- Gaussian数: 100K
- SH degree: 3

| 処理 | RTX 4090 | RTX 5090 | 差 |
|------|----------|----------|-----|
| Forward | 2870 FPS | 4169 FPS | +45% |
| Backward | 850 FPS | 1280 FPS | +51% |
| Training (it/s) | 50 | 77 | +54% |

## 機械学習トレーニング

**テスト条件:**
- モデル: ResNet-50
- バッチサイズ: 64
- データセット: ImageNet

| 項目 | RTX 4090 | RTX 5090 | 差 |
|------|----------|----------|-----|
| 画像/秒 | 1850 | 2650 | +43% |
| エポック時間 | 12分 | 8.5分 | -29% |

## LLM推論

**テスト条件:**
- モデル: LLaMA 2 7B

|------|----------|----------|-----|
| トークン/秒 | 45 | 72 | +60% |
| 初回応答 | 0.8秒 | 0.5秒 | -38% |

# 用途別推奨

## RTX 4090が向いているケース

```
推奨シナリオ:
├── 予算重視（40万→25万円）
├── 24GB VRAMで足りる用途
├── 既存環境との互換性重視
└── 安定性を最優先
```

## RTX 5090が向いているケース

```
推奨シナリオ:
├── 最高性能が必要
├── 32GB VRAMが必要（大規模モデル）
├── FP4/FP8推論を多用
├── 長期間使う予定（5年以上）
└── 電源容量に余裕がある（575W）
```

## 用途別マトリクス

|------|----------|----------|------|

| 3DGS（1M以上） | △ | ◎ | VRAMで5090 |
| LLM 7B | ◎ | ◎ | コスパで4090 |

| ゲーム 4K | ◎ | ◎ | コスパで4090 |
| ゲーム 8K | △ | ◎ | 5090推奨 |

# 移行の注意点

## ドライバ

```
RTX 5090:
├── CUDA 12.8以上必須
├── ドライバ590以上推奨
├── 古いアプリケーションは要確認
└── PyTorch 2.8以上推奨
```

## 電源コネクタ

```
12VHPWR/12V-2x6:
├── RTX 5090は12V-2x6採用
├── 変換ケーブルは非推奨
├── 対応電源への交換を検討
└── 接続不良に注意
```

## ケース互換性

```
サイズ確認:
├── RTX 5090: 340mm前後
├── 3スロット以上の厚み
├── 大型ケース推奨
└── ATXミドルタワー以上
```
