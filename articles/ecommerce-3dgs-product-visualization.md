**ECサイトで商品を3D表示したら、購買転換率が2倍になった。**

返品率も30%減少。「思ってたのと違う」が激減した。

# なぜ3D表示が効くのか

## 2D画像の限界

```
従来のEC:
├── 正面・側面・背面の写真
├── 360度回転（カクカク）
├── ズーム（2D画像の拡大）
└── サイズ感がわからない

結果:
├── 「思ってたより小さい」→ 返品
├── 「色が違う」→ 返品
├── 「質感がわからない」→ 購入見送り
```

## 3DGSの強み

```
3DGS表示:
├── 自由な角度から閲覧
├── リアルタイムでヌルヌル回転
├── フォトリアルな質感
├── AR配置（部屋に置いてみる）
└── VR試着（ファッション）

結果:
├── 購買転換率: 2倍
├── 返品率: 30%減
├── 滞在時間: 3倍
└── 顧客満足度: 向上
```

# 導入方法

## Step 1: 撮影

**必要なもの:**
- スマホ（iPhone 12以降推奨）
- 回転台（100均で可）
- 照明（自然光 or LEDライト）

**撮影手順:**
```
1. 商品を回転台に置く
2. スマホを固定（三脚推奨）
3. 回転台を回しながら動画撮影（1周30秒）
4. 上から、横から、下から（3アングル）
5. 合計2分の動画
```

## Step 2: 3DGS生成

**無料ツール:**
- [Luma AI](https://lumalabs.ai/) - スマホで完結、商用利用要確認
- [Polycam](https://poly.cam/) - 高品質、月額課金

**商用向け:**
- 自社サーバーで処理（機密保持）
- [HyperSplat](https://github.com/amabito/hyper-rasterizer) - Apache 2.0

## Step 3: ECサイトに組み込む

**ビューアオプション:**

```html
<!-- 埋め込み例 -->
<iframe
  src="https://your-viewer.com/product/12345"
  width="100%"
  height="400px"
></iframe>
```

**主要プラットフォーム対応:**
| プラットフォーム | 対応方法 |
|----------------|---------|
| Shopify | アプリで対応 |
| BASE | カスタムHTML |
| 楽天 | iframe埋め込み |
| Amazon | 未対応（2D画像のみ） |

# 技術的なポイント

## ファイルサイズ最適化

```
問題: 3DGSモデルは大きい（50-200MB）
解決:
├── LOD（Level of Detail）で段階表示
├── プログレッシブローディング
└── CDN配信
```

## モバイル対応

```
問題: スマホでの表示が重い
解決:
├── WebGPU対応ブラウザで高速化
├── 低解像度版を先に表示
└── タッチ操作の最適化
```

## SEO対策

```
問題: 3Dコンテンツはクローラーが認識しない
解決:
├── 静止画も併用
├── 構造化データでマークアップ
└── alt属性に商品説明
```

# よくある質問

## Q: 全商品を3D化すべき？

A: いいえ。優先順位をつける:
1. 高単価商品（ROIが高い）
2. 返品率が高い商品
3. サイズ感が重要な商品
4. 質感が売りの商品

## Q: 撮影スタジオは必要？

A: 最初は不要。窓際の自然光で十分。
本格化したら簡易スタジオ（5万円程度）を検討。

## Q: 動画と3DGS、どっちがいい？

A: 用途による:
- 動画: 使用シーンを見せたい
- 3DGS: 商品を自由に見たい

両方併用がベスト。
