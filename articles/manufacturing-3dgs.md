```
従来の3Dスキャン:

# 製造業での活用シーン

## 1. 設備レイアウト検討

**課題**: 新しい設備を導入する際、既存ラインとの干渉確認が大変

```
従来:
├── 現地で測量（半日）
├── 2D図面に落とし込み（1日）
├── CADでレイアウト検討（2日）
├── 干渉箇所を現地確認（半日）
└── 修正して再検討（繰り返し）

合計: 1〜2週間
```

**3DGSを使うと:**

```
3DGS:
├── スマホで工場内を動画撮影（30分）
├── 3DGSでモデル生成（2時間）
├── VRで設備配置をシミュレーション（1時間）
└── その場で関係者と合意

合計: 半日
```

## 2. 作業手順書の3D化

**課題**: 紙のマニュアルでは作業ポイントが伝わりにくい

**解決**: 3DGSモデルに作業ポイントをアノテーション

```
効果:
├── 新人教育時間: 2週間 → 3日
├── 作業ミス: 30%削減
└── 多言語対応: 視覚的なので翻訳不要
```

## 3. 遠隔支援・リモート監査

**課題**: 海外工場の監査に出張が必要

**解決**: 工場全体を3DGSでスキャン → リモートでウォークスルー

```
効果:
├── 出張費: 1回50万円 → 0円
├── 監査頻度: 年2回 → 月1回可能
└── 記録: 3Dモデルとして永久保存
```

## 4. 設備故障時の情報共有

**課題**: 電話で故障状況を説明するのが難しい

**解決**: 故障箇所を3DGSでスキャン → ベンダーに共有

```
効果:
├── 初回訪問での解決率: 60% → 90%

## Step 1: 小さく始める

```
おすすめ:
├── 対象: 1ラインだけ

├── 予算: 0円（スマホ + 無料ソフト）

```

## Step 2: 撮影のコツ

```
良い撮影:
├── 動画で撮る（写真より楽）
├── ゆっくり歩く（ブレ防止）
├── オーバーラップを意識（同じ場所を複数角度から）
└── 照明を均一に

悪い撮影:
├── 早歩きで撮る
├── 暗い場所をそのまま
├── 反射面が多い（鏡面仕上げの設備）
└── 動くもの（人、フォークリフト）
```

## Step 3: 3DGS生成

**無料ツール:**
- [Luma AI](https://lumalabs.ai/) - スマホアプリで完結
- [Polycam](https://poly.cam/) - 高品質、一部有料
- [nerfstudio](https://docs.nerf.studio/) - 自前サーバーで処理

**商用ツール:**
- [3D Gaussian Splatting公式](https://github.com/graphdeco-inria/gaussian-splatting) - 研究用途のみ
- [HyperSplat](https://github.com/amabito/hyper-rasterizer) - Apache 2.0、商用OK

# よくある質問

## Q: 機密情報は大丈夫？

A: クラウドサービスを使う場合は注意。機密性が高い場合は:
- オンプレミス環境で処理
- 商用OKのOSSを使用（HyperSplatなど）
- NDA締結済みのベンダーに依頼

## Q: 精度はどのくらい？

A: 撮影条件による。
- 良い条件: ±1-2cm
- 悪い条件: ±5-10cm
- LiDAR並みの精度が必要なら、LiDARを使うべき

## Q: 反射面が多い設備は？

A: 苦手。対策:
- 反射防止スプレー（一時的）
- 複数照明で反射を分散
- 反射面だけCADでモデリングして合成
