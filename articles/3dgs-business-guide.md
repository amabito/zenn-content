# 3DGSとは

## 30秒で分かる3DGS

```
従来: 3Dモデルを作るには専門家が数日〜数週間かけて手作業
3DGS: スマホで写真を撮るだけで、AIが数分で3Dモデルを生成
```

**写真から3Dを自動生成する技術**、それが3DGS。

## 実際の見た目

3DGSで作った3Dモデルは、写真と見分けがつかないレベルの品質。

- 360度どこからでも見られる
- 光の反射も再現
- ズームしても破綻しない

# 3DGSの仕組み（非技術者向け）

## 3ステップで完成

```
1. 撮影: 対象物を様々な角度から撮影（50〜200枚）
2. 処理: AIが写真から3D構造を推定（数分〜数時間）
3. 完成: ブラウザやアプリで3Dモデルを閲覧
```

## なぜ写真から3Dが作れるのか

人間が2枚の目で奥行きを認識するのと同じ原理。

```
左目の映像 + 右目の映像 → 脳が3Dを認識
複数枚の写真 + AI → 3Dモデルを生成
```

# 導入の落とし穴

## 落とし穴1: ライセンス問題

**3DGSの公式実装は商用利用に制限がある。**

```
オリジナル実装: Inria/Max-Planckライセンス → 商用は要契約
代替実装: ライセンスを要確認
```

「オープンソース＝自由に使える」ではない。

## 落とし穴2: 品質のばらつき

撮影条件によって品質が大きく変わる。

| 条件 | 良い | 悪い |
|------|------|------|
| 照明 | 均一、曇天 | 強い影、逆光 |
| 対象 | テクスチャあり | 単色、反射物 |
| 撮影 | オーバーラップ80% | 飛び飛び |

## 落とし穴3: 運用コスト

処理にはGPUが必要。

| 選択肢 | 初期コスト | 運用コスト |
|--------|----------|----------|
| 自社GPU | 50〜200万円 | 電気代のみ |
| クラウドGPU | 0円 | 月5〜50万円 |
| SaaS | 0円 | 従量課金 |
