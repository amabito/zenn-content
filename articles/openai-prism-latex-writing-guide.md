# 結論から言う

**OpenAI Prismは、GPT-5.2を搭載した無料のLaTeX論文執筆ワークスペースだ。Overleafの競合であり、AI統合という一点で大幅に上回る。**

2026年1月27日、OpenAIはPrismを公開した。ChatGPTアカウントがあれば無料で使える。下書き、改訂、数式処理、文献管理、共同作業、出版準備をひとつのクラウド環境で完結できる。

**この記事で得られること:**
- Prismの全機能と使い方
- Overleafとの詳細比較
- 3DGS/CV研究者にとっての実用性

---

# Prismとは何か

## 概要

| 項目 | 内容 |
|------|------|
| 開発元 | OpenAI |
| 搭載AI | GPT-5.2（数学・科学推論に最適化） |
| 価格 | 無料（ChatGPTアカウントが必要） |
| ベース技術 | Crixet（OpenAIが買収したLaTeXプラットフォーム） |
| プロジェクト数 | 無制限 |
| コラボレーター数 | 無制限 |
| URL | https://prism.openai.com/ |

## 経緯

PrismはOpenAIが買収したCrixetをベースに構築された。CrixetはクラウドベースのLaTeXエディタで、独自のAIアシスタント「Chirp」を搭載していた。OpenAIはこれをGPT-5.2で置き換え、Prismとしてリブランドした。Crixetは単独サービスとしては終了。

## OpenAIのビジョン

> 「2025年にAIがソフトウェア開発を変えたように、2026年にAIが科学を変える」
> --- Kevin Weill, VP of OpenAI for Science

ChatGPTへの科学・数学関連クエリは週800万件超。この需要に応える専用ツールとしてPrismが生まれた。

# Prismの全機能

## 1. LaTeXネイティブエディタ

- クラウドベースのフルLaTeXエディタ
- リアルタイムプレビュー
- テンプレート（論文フォーマット）対応
- ファイル管理（.tex、.bib、画像等）

## 2. GPT-5.2の深い統合

従来のAIチャットボットとは根本的に異なる。

```
従来のAI論文支援:
  論文エディタ（Overleaf等） + 別タブでChatGPT → コピペで行き来

Prismの統合:
  論文の構造・数式・参考文献・文脈をGPT-5.2が直接理解
  → エディタ内で完結する支援
```

### GPT-5.2にできること

| 機能 | 説明 |
|------|------|
| **文章の起草・改訂** | 論文全体の文脈を理解した上で執筆支援 |
| **数式の推論** | LaTeX数式を読み取り、導出の正当性を検証 |
| **文献提案** | arXiv等から関連文献を自動提案 |
| **引用管理** | 適切な引用を自動挿入 |
| **手書き→LaTeX変換** | 手書き数式の写真をLaTeXコードに変換 |
| **図表→LaTeX変換** | ホワイトボードの図をLaTeXダイアグラムに変換 |
| **音声編集** | 音声ベースで論文を編集 |

## 3. 手書き数式のコード変換

研究者にとって最も実用的な機能の一つ。

- ホワイトボードや紙に書いた数式を写真撮影
- GPT-5.2のビジュアル機能で認識
- LaTeXコードに自動変換

### 使い所

- セミナーのホワイトボードメモを即座にLaTeX化
- 手計算の導出過程を論文に取り込む
- 図解からTikZコードを生成

## 4. リアルタイム共同作業

- 複数の研究者が同時に編集
- コラボレーター数に制限なし
- GPT-5.2が共同作業の文脈も理解

## 5. 出版準備

- 学会テンプレート（IEEE、ACM、NeurIPS等）への対応
- 参考文献フォーマットの自動調整
- プレプリントサーバー（arXiv）への投稿準備

# Overleafとの比較

## 機能比較表

| 機能 | **Prism** | **Overleaf** |
|------|-----------|-------------|
| LaTeXエディタ | 完全対応 | 完全対応 |
| リアルタイム共同編集 | あり | あり |
| **AIアシスタント** | **GPT-5.2搭載** | **なし（基本的な補完のみ）** |
| 価格 | 無料 | フリーミアム（有料プランあり） |
| 共同編集者数 | **無制限** | 無料プランでは制限あり |
| 文献提案 | **AI自動提案** | 手動 |
| 手書き→LaTeX | **対応** | 非対応 |
| 音声編集 | **対応** | 非対応 |
| **オープンソース** | なし | **あり（セルフホスティング可能）** |
| オフライン利用 | 不可 | セルフホスティング版なら可 |
| 実績 | 新サービス | 10年以上の実績 |
| Gitバージョン管理 | 不明 | あり |

## Prismの明確な優位点

1. **AI統合**: これが最大の差別化。論文の文脈を理解したAIが執筆を支援
2. **完全無料**: Overleafの有料機能（共同編集者数拡大等）に相当する機能が無料
3. **手書き変換**: ホワイトボードの数式やダイアグラムをそのままLaTeX化

## Overleafの優位点

1. **実績と安定性**: 10年以上の運用実績。多くの学会・大学で採用
2. **オープンソース**: セルフホスティング可能。データ主権を確保できる
3. **Gitバージョン管理**: 論文のバージョン管理がGitベースで確実
4. **エコシステム**: 既存のテンプレート、パッケージ、コミュニティが充実

## どちらを使うべきか

| ユースケース | 推奨 |
|-------------|------|
| 新規論文の執筆開始 | Prism（AI支援で効率的） |
| 既存プロジェクトの継続 | Overleaf（移行コストが高い） |
| 大学・組織のポリシーが厳しい | Overleaf（セルフホスティング可能） |
| 個人研究・プレプリント | Prism（無料で高機能） |
| 数式の多い論文 | Prism（手書き変換、数式推論） |
| 長期的な論文管理 | Overleaf（Git統合、実績） |

# 3DGS/CV研究者としての活用法

## 筆者の研究開発分野

3D Gaussian Splatting（3DGS）のCUDAラスタライザ開発とWebGPUビューア開発を行っている。論文を書く場面は以下の通り。

- 技術レポート、ホワイトペーパー
- 手法の理論的背景の整理
- ベンチマーク結果の公開

## Prismが特に役立つ場面

### 1. 数式の導出と検証

3DGS論文には数式が大量に出現する。

- **ガウシアン分布の射影公式**: 3D→2Dの射影変換
- **球面調和関数（SH）の展開**: 色表現の数学的基盤
- **勾配計算**: ラスタライズの微分可能性の証明

GPT-5.2が数式の導出を検証できるのは大きい。手計算の転記ミスを自動検出できる。

### 2. 関連研究のサーベイ

```
Prismの使い方:
1. 論文にIntroductionを書き始める
2. GPT-5.2が関連するarXiv論文を自動提案
3. 引用を挿入し、Related Workセクションを構築
```

3DGS分野はプレプリントの更新が週単位で発生する。arXiv連携は実用的だ。

### 3. 図解の生成

- ラスタライゼーションパイプラインの図解
- ベンチマーク結果の表やグラフ
- アーキテクチャ図

ホワイトボードにざっくり描いた図をPrismに取り込み、TikZやPGFPlotsのコードに変換できる。

### 4. 技術レポートの高速執筆

学会論文でなくても、チーム内の技術レポートやOSSのドキュメントをLaTeXで書く場面は多い。Prismなら以下が高速化される。

- 実験結果の表の自動フォーマット
- アブストラクトの推敲
- 英語論文の文法・表現チェック

# 注意点と限界

## 現時点の制限

1. **新サービスゆえの不安定性**: リリース直後のため、バグや機能不足がある可能性
2. **データプライバシー**: 論文データがOpenAIのサーバーに送信される。未発表の研究には注意
3. **セルフホスティング不可**: 機密性の高い研究にはOverleafのセルフホスティング版が適切
4. **有料機能の予告**: 現在は無料だが、将来的にChatGPTの有料プランに連動する高度機能が追加予定

## 使い分けの提案

```
未発表の最先端研究 → Overleaf（セルフホスティング）
プレプリント・技術レポート → Prism（AI支援で高速化）
学会のカメラレディ → Overleaf（テンプレート実績）
個人の学習・メモ → Prism（無料で十分）
```

# まとめ

| 観点 | 評価 |
|------|------|
| AI統合 | GPT-5.2の深い統合は競合ゼロ。Overleafにはない機能 |
| 価格 | 完全無料。プロジェクト数・コラボレーター数の制限なし |
| LaTeX機能 | Crixetベースで十分実用的。ただしOverleafの10年の実績には及ばない |
| 手書き変換 | 研究者にとって最も実用的な機能。数式・図解を即LaTeX化 |
| 3DGS/CV研究 | 数式導出の検証、文献サーベイ、図解生成で有用 |
| 注意点 | データプライバシー、新サービスの不安定性、将来の有料化 |

**Prismは「AIネイティブな論文執筆環境」という新カテゴリを開拓した。** Overleafを完全に置き換えるものではないが、AI支援による執筆効率の向上は圧倒的だ。特に数式の多い3DGS/CV分野では、手書き変換と数式推論が強力な武器になる。
