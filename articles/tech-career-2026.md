# 結論から言う

**AI時代に生き残る技術者は「AIを使いこなす側」になる。**

本業は建設コンサルタント兼3DGSエンジニア。業界15年の経験と、最新技術への取り組みから見えたキャリア戦略を共有する。

---

# 2026年の技術者を取り巻く環境

## 何が変わったか

| 2020年 | 2026年 |
|--------|--------|
| AIは研究段階 | **AIが実用化** |
| コードを書く = 価値 | コードは**AIが書く** |
| 専門性 = 安泰 | 専門性 + **AI活用** = 価値 |

## AIに奪われる仕事、奪われない仕事

| 奪われる | 奪われない |
|---------|-----------|
| 定型的なコーディング | 要件定義・設計 |
| ドキュメント作成 | 顧客との折衝 |
| テストコード作成 | アーキテクチャ判断 |
| バグ修正 | 新技術の開拓 |

# キャリア戦略の3つの方向性

## 方向性1: AIを使いこなすエンジニア

```
特徴: AIツールを駆使して生産性を10倍に
需要: 全業界で増加
年収: 600〜1,500万円
```

### 必要スキル

- プロンプトエンジニアリング
- AIツール活用（Cursor、GitHub Copilot等）
- 品質管理（AIの出力を評価・修正）

## 方向性2: AIを作るエンジニア

```
特徴: AI/MLモデルの開発・最適化
需要: AI企業、研究機関
年収: 800〜2,000万円
```

### 必要スキル

- Python、PyTorch/TensorFlow
- 数学（線形代数、確率統計）
- GPU最適化（CUDA）

## 方向性3: 業界特化エンジニア

```
特徴: 特定業界 × 技術の掛け算
需要: 各業界で希少人材
年収: 700〜1,500万円
```

### 例

- 建設 × 3DGS
- 医療 × AI
- 金融 × ブロックチェーン
- 製造 × デジタルツイン

# 年収を上げる方法

## 方法1: 転職（即効性あり）

```
現職で年収据え置き → 転職で20%アップはよくある話
```

| 転職パターン | 年収変動 |
|------------|---------|
| 同業他社 | +10〜30% |
| 異業種（スキル活かす） | +20〜50% |
| 外資系 | +50〜100% |

## 方法2: 副業（リスク低）

```
本業の知識を副業に活かす
├── 技術ブログ → 月5〜50万円
├── 技術顧問 → 月10〜30万円
├── 受託開発 → 案件次第
└── 教育・研修 → 日当5〜10万円
```

## 方法3: スキルアップ（長期的）

```
資格取得 → 市場価値向上
├── 技術士 → +100〜200万円
├── AWS認定 → +50〜100万円
├── PMP → +50〜100万円
└── 情報処理 → +30〜50万円
```

# 私の失敗談

## 失敗1: 「技術だけ」で勝負しようとした

```
20代: 「技術力があれば評価される」
現実: ビジネス貢献しないと評価されない
```

**技術は手段、ビジネス貢献が目的。**

## 失敗2: 資格取得を後回しにした

```
20代: 「実務経験の方が大事」
30代: 「資格がないから提案が通らない」
```

**資格は「信頼の証明」。実力と資格、両方必要。**

## 失敗3: 一つの会社に依存しすぎた

```
10年同じ会社 → 市場価値が見えなくなる
転職活動で現実を知る → 「井の中の蛙」だった
```

**定期的に市場価値を確認すべき。**
