# 結論から言う

**建設コンサルタントのDXは「やりたくてもできない」構造問題だ。**

「なぜ建設業はDXが遅れているのか？」

現場15年の建設コンサルタントが、業界の内側から本音で語る。そして、3DGSがこの状況を変える可能性についても。

**この記事で得られること:**
- DXが進まない5つの構造的理由
- 成功している会社の共通点
- 3DGSという突破口

---

# 建設コンサルタント業界の現状

## 数字で見る危機

| 指標 | 数値 | 出典 |
|------|------|------|
| 55歳以上の就業者割合 | 35.5% | 国土交通省 |
| 2030年の技能者不足予測 | 94万人 | 国土交通省 |
| 建設業有効求人倍率 | 5倍以上 | 厚生労働省 |
| 躯体工事の求人倍率 | **7.65倍** | 厚生労働省 |

**10年後、現場を支える人がいなくなる。**

これは誇張ではない。団塊世代が2025年に75歳を超え、大量に労働市場から離脱する「2025年問題」は建設業を直撃している。

## 2024年問題の追い打ち

2024年4月から、建設業にも労働時間の上限規制が厳格適用された。

```
従来: 残業で何とかカバー
2024年以降: 残業すらできない
```

人が足りない上に、働ける時間も減った。**効率化しないと現場が回らない。**

# なぜDXが進まないのか

## 理由1: 初期投資が高すぎる

| 機器 | 価格帯 |
|------|--------|
| 地上型レーザースキャナー | 1,000〜3,000万円 |
| ICT建機 | 約3,000万円 |
| 写真測量ドローン | 100〜300万円 |
| BIM/CIMソフトウェア | 年間100〜500万円 |

建設業界の大半は**資本金1,000万円以下の中小企業**だ。3,000万円の機材を買える会社がどれだけあるか。

## 理由2: 人材がいない

BIM/CIMを導入しない理由の調査結果:

| 理由 | 割合 |
|------|------|
| 習熟するまで業務負担が大きい | 59.3% |
| 人材がいない/育成コストが高い | 51.8% |
| 導入効果が実感できない | - |

高齢化が進む現場で、「新しいソフトを覚えろ」は酷だ。覚える側も教える側も疲弊する。

## 理由3: 業界構造の問題

建設業は多重下請け構造だ。

```
元請け
  └─ 一次下請け
       └─ 二次下請け
            └─ 三次下請け
                 └─ ...
```

下請けが「DXしたい」と思っても、元請けの仕様に合わせる必要がある。**自社だけでは決められない。**

## 理由4: 二重作業の罠

現実として起きていること:

> 発注者が2次元図面しか提供しないため、受注者側で3次元化する二重作業が発生し、生産性向上に繋がらない

BIM/CIMが「原則適用」されても、紙の図面がなくならない限り、作業は増えるだけだ。

# BIM/CIM普及の現実

## 導入率は半分以下

国土交通省の2022年調査:

| 項目 | 数値 |
|------|------|
| BIM導入企業 | **48.4%** |
| 未導入企業 | 51.6% |

2023年から「原則適用」が始まったが、2025年になっても全面普及には程遠い。

## 企業規模による格差

建設コンサルタント会社の3次元CIMモデル導入率:

| 売上規模 | 導入率 |
|---------|--------|
| 上位100社 | 約61% |
| 101位以下 | **33.3%** |

**中小は置いていかれている。**

# 3DGSという選択肢

## 既存技術の限界

| 手法 | 時間 | コスト | 結果 |
|------|------|--------|------|
| 地上型レーザースキャナー | 1日/現場 | 機材数百〜数千万円 | 点群（粒状感あり） |
| ドローン写真測量 | 1-2時間 | 機材100〜300万円 | 点群（粒状感あり） |
| 通常の3Dスキャン | 数時間 | 高額 | メッシュ（重い） |

点群は「点の集まり」なので、どうしても見た目が荒い。発注者への説明には使いにくい。

## 3DGSの特徴

3D Gaussian Splatting（3DGS）は、2023年にSIGGRAPHで発表された新しい3D表現技術だ。

| 項目 | 点群 | 3DGS |
|------|------|------|
| 見た目 | 粒状感がある | **写真のように自然** |
| レンダリング | 遅い | **リアルタイム** |
| データサイズ | 大（数GB） | 中（数百MB） |
| 必要機材 | 専用スキャナー | **スマホでも可** |

## 建設現場での3DGS

STUDIO55社の事例:

> 通常5時間かかる現況測量を、わずか1時間で完了

**時間が1/5になる。**

図面がない既存物件でも、スキャンからBIM・図面作成・VR化までシームレスに連携できる。

# 3DGSの建設現場活用シーン

## 1. 施工管理

- 出来形をリアルタイムで3D確認
- 設計との差異を視覚的に把握
- 遠隔地からの進捗確認

## 2. 発注者への説明

点群を見せても「何これ？」と言われる。

3DGSなら写真のような品質で、**素人にも一目で伝わる。**

## 3. 維持管理

- 構造物の経年変化を記録
- ひび割れ、変状の可視化
- 補修計画の根拠資料

## 4. 安全管理

- 危険箇所の3D可視化
- 新規入場者教育
- リモート安全巡視

# 3DGS導入の現実的ハードル

## 商用利用の問題

オリジナルの3DGS実装は**商用利用できない**。

```
diff-gaussian-rasterization
├── ライセンス: Gaussian-Splatting License
├── 商用利用: ❌ Inria/Max-Planckとの契約が必要
└── 現実: 大企業以外は門前払い
```

建設業務で使うなら、商用OKな実装が必要:

| 実装 | ライセンス | 商用利用 |
|------|-----------|---------|
| gsplat | Apache 2.0 | ✅ |
| HyperRasterizer | Apache 2.0 | ✅ |

## 動く物体問題

建設現場は人や車両が動く。3DGSは動く物体が苦手。

**解決策:**
- 早朝・休日に撮影
- floater（浮遊ノイズ）除去処理
- マスク処理で動体を除外

## スケール問題

3DGSはスケールレス。測量に使うなら、GCP（基準点）設置が必要。

# 中小建設コンサルタントへの提言

## 1. 「全部やる」から「一部から」へ

BIM/CIMを全業務に適用しようとして失敗するケースが多い。

まずは**発注者説明用の3Dビジュアル**だけでも3DGSを試してみてほしい。

## 2. スマホLiDARから始める

iPhone Pro/iPad ProにはLiDARが搭載されている。

| 機材 | 価格 |
|------|------|
| 専用レーザースキャナー | 1,000万円〜 |
| iPhone 15 Pro | 16万円 |

まずは手持ちのスマホで、オフィスや小規模現場を3D化してみる。**体験から始める。**

## 3. 補助金を活用する

| 補助金 | 上限 | 対象 |
|--------|------|------|
| IT導入補助金 | 450万円 | ITツール導入 |
| ものづくり補助金 | 3,000万円 | 3D計測機器、ICT建機 |
| 中小企業省力化投資補助金 | - | 3Dレーザースキャナー、GNSS測量機 |
